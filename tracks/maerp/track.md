# maERP

Правила проекта maERP — собственной конфигурации на платформе 1С, написанной
с нуля. К типовой 1С:ERP Управление предприятием (направление `erp`) она
отношения не имеет: общие у них только платформа и язык.

Сюда попадает то, что верно именно для maERP: её объекты, соглашения и
приёмы. То, что верно для любой конфигурации, живёт в `core`, а общие приёмы
разработки с нуля — в `greenfield`.

Направление заведено пустым: правила приходят из «Базы знаний ИИ» портала
TinyCIO PR-ами `intake/*` после проверки человеком.
