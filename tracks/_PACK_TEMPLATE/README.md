# Заготовка пакета инструкций по конфигурации

Скопировать файлы в `tracks/<направление>/` и заполнить; формат — README,
раздел «Пакет инструкций по конфигурации». Каталог с подчёркиванием манифест
пропускает, поэтому заготовка направлением не считается.

| файл | что внутри |
|---|---|
| `profile.json` | паспорт: как узнать конфигурацию по `Метаданные.Имя`, версии и поставщику; у `ka`/`erp` — `"расширяет": "ut"` |
| `where_is.md` | таблица «что → раздел → путь → как открыть»: журналы, документы, отчёты, настройки |
| `objects.md` | карта объектов: документ → роль → чем закрывается; справочники; регистры |
| `notes.md` | особенности: «в этой конфигурации нет …», «НДС считается …», «закрытие месяца — …» |
| `faq.md` | типовые вопросы пользователя и короткие ответы-маршруты |
| `chips.json` | подсказки-чипы: `id`, `заголовок`, `текст`; необязательные `тема`, `подсказка`, `параметры`, `проверить` |
| `sources.md` | источники фактов `S-n` с URL — для ревью, в пакет не входит |

В промпт уходит выжимка (профиль, `where_is.md`, `notes.md`, чипы; потолок
24 КБ): строки с `[проверить]`, разделы «… (подробно)», колонки «статус» и
ссылки `(S-n)` в неё не попадают; `objects.md` и `faq.md` — по запросу.

## Навыки: каталог `skills/`

Рядом с файлами пакета можно положить каталог `skills/` с навыками: `skills/<имя>.md`, один навык — один файл
(имя: `a-z`, цифры, дефис). Навык — подробная инструкция «по запросу»: в промпт идёт только строка `когда`, текст
помощник забирает сам (`get_skill`). У `core/skills/` навыки общие для всех направлений.

```
---
имя: reports
заголовок: Штатные отчёты
когда: просят оборотно-сальдовую ведомость или карточку счёта
нужно: {"caps":[],"access":[]}
запуск: {"text":"Сформируй ОСВ за {period}","params":[{"key":"period","label":"Период","kind":"period","required":true}]}
источник: измерение: что и как проверено, ГГГГ-ММ-ДД
---
# Заголовок навыка
Текст: что делать и чего не делать.
```

- Обязательны `имя` (равно имени файла), `заголовок` (до 60 рун), `когда` (до 200 рун), `источник` (вид из списка, как
  у правил).
- `нужно` (необязательно) — JSON `{"caps":[…],"access":[…]}`: что нужно от расширения 1С.
- `запуск` (необязательно) — навык, который бухгалтер запускает кнопкой «Запустить»: JSON `{"text":…,"params":[…]}`;
  `text` — одна строка до 300 рун без ссылок и разметки, подстановки `{ключ}`; параметров до четырёх
  (`key`, `label`, `kind` из `text`/`inn`/`period`, `required`), каждый стоит в тексте. Без `запуск` навык видит
  только помощник.
- Тело до 16 КБ, навыков на направление до 20, сумма тел до 96 КБ; без ссылок; строки с `[проверить]` помощнику не
  отдаются.
