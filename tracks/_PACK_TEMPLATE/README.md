# Заготовка пакета инструкций по конфигурации

Скопировать файлы в `tracks/<направление>/` и заполнить; формат — README,
раздел «Пакет инструкций по конфигурации». Каталог с подчёркиванием манифест
пропускает, поэтому заготовка направлением не считается.

| файл | что внутри |
|---|---|
| `profile.json` | паспорт: как узнать конфигурацию по `Метаданные.Имя`, версии и поставщику; у `ka`/`erp` — `"расширяет": "ut"` |
| `where_is.md` | таблица «что → раздел → путь → как открыть»: журналы, документы, отчёты, настройки |
| `objects.md` | карта объектов: документ → роль → чем закрывается; справочники; регистры |
| `notes.md` | особенности: «в этой конфигурации нет …», «НДС считается …», «закрытие месяца — …» |
| `faq.md` | типовые вопросы пользователя и короткие ответы-маршруты |
| `chips.json` | подсказки-чипы: `id`, `заголовок`, `текст`; необязательные `тема`, `подсказка`, `параметры`, `проверить` |
| `sources.md` | источники фактов `S-n` с URL — для ревью, в пакет не входит |

В промпт уходит выжимка (профиль, `where_is.md`, `notes.md`, чипы; потолок
24 КБ): строки с `[проверить]`, разделы «… (подробно)», колонки «статус» и
ссылки `(S-n)` в неё не попадают; `objects.md` и `faq.md` — по запросу.
