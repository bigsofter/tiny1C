# Типовые вопросы бухгалтера: Бухгалтерия предприятия 3.0

Короткие ответы-маршруты: что сделать инструментами, куда направить человека. Пути — в where_is.md, подробности —
в notes.md.

| вопрос | ответ-маршрут |
|---|---|
| Сколько нам должен контрагент / кому должны мы | run_report ОСВ или Анализ счёта по 62 / 60 (76) с отбором по контрагенту на дату; для руководителя — «Руководителю › Общие показатели › Расчёты с покупателями и поставщиками» |
| Сделай ОСВ за период | run_report Оборотно-сальдовая ведомость; ссылка app:Отчет.ОборотноСальдоваяВедомость |
| Всё ли готово к закрытию месяца / нет ли хвостов | check_month_close за нужный месяц и организацию; дальше — маршрут «Операции › Закрытие периода › Закрытие месяца» |
| Закрой месяц | сама не закрываю: проверяю (check_month_close), показываю список хвостов, маршрут на помощник закрытия; четыре блока по порядку, обособленные подразделения — блоки 1 и 3 по каждому |
| Месяц не закрывается, ошибка в регламентной операции | текст ошибки — в карточке операции; типовые причины: нарушена последовательность (серая ссылка «Перепроведение»), минусы в ОСВ, не рассчитана база распределения 25/26 по подразделению, изменена учётная политика; перепроведение — «Операции › Сервис › Групповое перепроведение» |
| Загрузи выписку / оплата прошла? | выписку грузит человек: «Банк и касса › Банк › Банковские выписки › Загрузить» (файл или ДиректБанк); оплату вижу по «Списание с расчётного счёта» / «Поступление на р/с» и по сальдо 51 |
| Оплати счёт поставщика | найти счёт по номеру и контрагенту (или создать из вложения), платёжка на основании — черновик без проведения; отправка в банк — человеком из списка платёжек |
| Проведи поступление и зарегистрируй счёт-фактуру | поступление (post) + СФ полученный на основании одним планом; номер и дату входящего — из документа |
| Почему СФ не попал в книгу покупок | без флажка «Отразить вычет…» и при раздельном учёте запись делает «Формирование записей книги покупок»; проверить проведённость поступления и СФ, период, Помощник по учёту НДС |
| Сформируй книгу покупок / продаж / декларацию | отчёты «Отчёты › НДС › Книга покупок / Книга продаж» через run_report, если есть; декларация — Помощник по учёту НДС и 1С-Отчётность (человек) |
| Нужен акт сверки с контрагентом | открыть «Акт сверки расчётов» заполненным (prefill_form: организация, контрагент, договор, период); электронно — «В электронном виде» и ЭДО |
| Поставь / сними дату запрета | только администратор: «Администрирование › Настройки пользователей и прав › Даты запрета изменения»; в закрытый период не пишу |
| Дай права пользователю / не вижу пункт меню | права и роли — администратор; пункт может быть выключен в «Главное › Настройки › Функциональность» или не положен роли |
| Какие налоги и когда платить | «Главное › Задачи организации» — сроки и помощники; уведомление и Операция по ЕНС — «Операции › Единый налоговый счёт» |
| Уведомление по ЕНС отправили с ошибкой | уточняющее не отменяет прежнее — сторнировать ошибочное (Операция, введённая вручную › Сторно), затем новое |
| Переходим на НДС 22% / НДС на УСН | ставка по дате отгрузки; проверить ставки в номенклатуре и «Налоги и отчёты»; релиз не ниже 3.0.186; пороги УСН 20 / 272,5 / 490,5 млн ₽ |
| Проверь учёт на ошибки | экспресс-проверка и анализ учёта — «Отчёты › Анализ учёта» (человек запускает); сама — запросами: непроведённые, минусы, незачтённые авансы |
| Сделай сторно / ручную проводку | «Операция (бухгалтерский учёт)» — ручные проводки планом с подтверждением; сторно документа — человеком в «Операции, введённые вручную › Сторно документа» |
| Распечатай документ | кнопка «Печать» в форме документа или списка; могу отдать файл (make_file / run_report output=file) |
| Покажи последние продажи / покупки за месяц | run_query по Документ.РеализацияТоваровУслуг / ПоступлениеТоваровУслуг с Проведен и датой за период, ПЕРВЫЕ N по убыванию даты |
| Остатки товаров на складе | run_query Остатки регистра бухгалтерии по 41 (10, 43) с Организацией и складом; или типовой отчёт остатков через run_report |
| Что ты меняла в базе | list_changes за нужное число дней |
