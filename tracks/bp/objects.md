# Карта объектов: 1С:Бухгалтерия предприятия 3.0

Ключевые объекты и связи — какой документ чем закрывается и куда смотреть. Имена метаданных со значком «✓»
помощник видел в живых базах; строки с [проверить] — имя ожидаемое, сверять через describe_metadata. Содержимое
конфигурации (модули, макеты) здесь не приводится и приводиться не будет.

## Покупки

| объект | роль | закрывается / порождает |
|---|---|---|
| Документ.СчетНаОплатуПоставщика ✓ | счёт от поставщика (намерение платить) | → Платёжное поручение (на основании), → Доверенность |
| Документ.ПоступлениеТоваровУслуг ✓ | поступление товаров, материалов, услуг, ОС (виды операций: Товары, Услуги, Товары+услуги, Оборудование…) | → Счёт-фактура полученный (на основании, один на поступление); закрывает аванс поставщику при проведении |
| Документ.СчетФактураПолученный ✓ | регистрация входящего СФ; виды: на поступление, на аванс, корректировочный, исправление | вычет: флажком «Отразить вычет НДС в книге покупок датой получения» или через «Формирование записей книги покупок» |
| Документ.ВозвратТоваровПоставщику ✓ | возврат поставщику | только на основании проведённого поступления; строки с себестоимостью заполняет 1С |
| Документ.ПоступлениеДопРасходов [проверить] | доставка и прочее сверх цены товаров | распределяется на себестоимость поступления |
| Документ.КорректировкаПоступления [проверить] | исправление/корректировка по согласованию | корректировочный или исправленный СФ |

| Документ.УстановкаЦенНоменклатуры ✓ | цены по видам цен | действует на всю базу с даты документа |

## Учёт и закрытие

| объект | роль |
|---|---|
| Документ.ОперацияБух ✓ | ручные проводки, сторно документа, типовая операция; строки проводок заменяют проводки целиком |
| Документ.РегламентнаяОперация ✓ | шаги закрытия месяца (амортизация, закрытие 20/23/25/26, 90/91, НДС…); создаёт помощник закрытия — не записывать |
| Последовательность «Документы организаций» [проверить] имя | граница последовательности проведения; нарушена → помощник закрытия требует перепроведения |
| ПланСчетов.Хозрасчетный ✓ | план счетов; ВидыСубконто — ПланВидовХарактеристик.ВидыСубконтоХозрасчетные ✓ |
| РегистрБухгалтерии.Хозрасчетный [проверить] | проводки БУ/НУ; Остатки/Обороты — всегда с Организацией и нужными субконто |
| РегистрНакопления.НДСПокупки / НДСПродажи ✓ (S-12) | источник книги покупок / книги продаж |
| РегистрСведений «Счета учёта расчётов с контрагентами» [проверить] имя | подстановка 60/62/76 по организации, контрагенту, договору, валюте — приоритет у частного |
| Справочник.Организации ✓, Пользователи ✓, ГруппыДоступа ✓ | служебные и опасные для записи — помощник не трогает |

| задача | где смотреть |
