# Особенности: 1С:Бухгалтерия предприятия 3.0

Что знать о конфигурации, прежде чем отвечать.

## Коротко

- Три варианта поставки — ПРОФ, КОРП, Базовая; имя конфигурации у ПРОФ `БухгалтерияПредприятия`, у КОРП
  `БухгалтерияПредприятияКОРП`. У части вариантов нет некоторых объектов — тип документа искать через метаданные, а
  не считать, что он есть (опыт).
- Два интерфейса: полный и простой; пути в пакете — для полного (в простом «Деньги» вместо «Банк и касса») (S-3).
- «Нет пункта в меню» чаще всего значит «не включено в Главное › Настройки › Функциональность» или «не положено
  роли», а не «в программе такого нет»; снять флажок возможности, по которой уже вёлся учёт, нельзя (S-24).
- Остатки регистра бухгалтерии сворачивают сальдо по полям выборки: без Организации и склада минус одного склада
  гасится плюсом другого. Всегда выбирать Организацию и нужные субконто (опыт). Минус по сумме при нулевом
  количестве — не ошибка, его исправит корректировка стоимости при закрытии месяца; красный — минус по количеству (опыт).
- Расчёты с контрагентами: на 60/62/76 субконто Контрагенты, Договоры, Документы расчётов; счёт подставляется из
  настроек счетов учёта расчётов, частная настройка важнее общей; справочник «Договоры» скрыт, пока не включён
  учёт по договорам (S-19).
- Закрытие месяца: Операции › Закрытие периода › Закрытие месяца, четыре блока строго по порядку; серая ссылка
  «Перепроведение документов» — нарушена последовательность, сначала перепровести; обособленные подразделения —
  блоки 1 и 3 по каждому, 2 и 4 по организации в целом (S-5, S-6). Помощник месяц не закрывает: регламентные
  операции в запрете, его дело — проверить готовность и дать маршрут.
- Платёжное поручение — не оплата: «Оплачено» и списание появляются с выпиской. Говорить «подготовила платёжку», а
  не «оплатила» (из промпта).
- Книги покупок и продаж строятся по регистрам накопления НДСПокупки и НДСПродажи, а не по проводкам; при вводе
  задним числом — перепроведение. Один СФ на одно основание: если 1С говорит «уже есть» — так и передать (S-12, опыт).
- Вычет по входящему СФ: либо флажок «Отразить вычет НДС в книге покупок датой получения» в самом СФ, либо
  регламентный документ «Формирование записей книги покупок» — обязателен при раздельном учёте (S-13).
- ЕНС: расчёты на счёте 68.90; начисление — «Уведомление об исчисленных суммах налогов» (Операции › Единый
  налоговый счёт); уточняющее уведомление прежнее не отменяет — ошибочное сторнировать (S-9). Сроки и помощники по
  налогам — Главное › Задачи организации (S-22).
- 2026: НДС 22 % с 01.01.2026 (релиз 3.0.186.21 и новее), ставка по дате отгрузки; НДС на УСН: до 20 млн ₽ —
  освобождение, 20–272,5 млн — 5 % или 22 %, 272,5–490,5 млн — 7 % или 22 % (S-21, S-25, S-27).
- Акт сверки с 3.0.131 выставляется и принимается в электронном формате ФНС через ЭДО (S-10); помощник открывает
  акт заполненным, не записывает.
- Дата запрета изменения ставится администратором с полными правами; закрытый период не обходить — предложить
  другую дату или администратора (из промпта, S-26).

## Варианты и интерфейс (подробно)

- «Функциональность» бывает основная, выборочная и полная; выключенный раздел не виден в меню (S-24).
- Команда «Все функции» выключена по умолчанию; включается в параметрах (S-7). Через неё видно всё, но это обход
  интерфейса — советовать осторожно.
- Имя конфигурации у Базовой версии: скорее всего то же `БухгалтерияПредприятия`, отличается только синоним
  («… (базовая)») [проверить] по фактам первой базовой базы.
- Признак регистров расчёта в пакете не утверждается: сервер берёт его из фактов базы [проверить].
- Объекты «настройка без программирования» в профиле — ожидаемые для БП 3.0; `Справочник.ВариантыОтчетов` — имя
  [проверить], поэтому в профиль не включён.

## Закрытие месяца (подробно)

- Выполнять можно по одной операции («Выполнить операцию») или все сразу («Выполнить закрытие месяца»); с 3.0.144
  одной кнопкой закрываются и несколько прошлых месяцев (S-5).
- Итог — «Состояние: Выполнено» в шапке; детали — проводки, справки-расчёты, «Отчёт о выполнении операций» (S-5).
- Без разбивки по подразделениям на втором шаге будет «Нарушена последовательность регламентных операций» (S-6).
- До закрытия: зарплата начислена, дубли и помеченные на удаление убраны, документы перепроведены, ОСВ без минусов,
  взаиморасчёты сверены, период закрыт датой запрета для остальных; в квартальные месяцы — регламентные операции НДС
  через помощник (S-5).
- После: на 25 и 26 остатков быть не должно; остаток на 20/23 допустим (зависит от учёта НЗП), на 44 — в пределах
  нормируемых затрат; затем Отчёты › Анализ учёта (экспресс-проверка, анализ по НДС и прибыли) и ОСВ ещё раз (S-5).
- Типовые причины сбоев: нарушенная последовательность; минусы в ОСВ; ручные операции по зарплате, которых помощник
  закрытия не видит (он проверяет только документ «Начисление зарплаты»); нет резерва отпусков — не включён флажок в
  настройках зарплаты; нет операций по сомнительным долгам — флажок в учётной политике БУ; расхождения по округлению
  налогов — счёт 99.09 (S-5). Не закрываются 20/23/25/26 — чаще всего не рассчитана база распределения для
  подразделения или номенклатурной группы, либо изменена учётная политика в действующей базе (S-28, S-29).
- «Групповое перепроведение» перепроводит все документы организации за период, не выборочно; при настройке «При
  закрытии месяца» себестоимость, зачёт авансов и погашение долга пересчитывают регламентные операции — их тоже
  перепроводить (S-7). Выборочно — обработка «Перепроведение документов» в «Все функции › Стандартные».
- Перенос границы последовательности без перепроведения — отдельное право (роль «Право интерактивного переноса
  границы последовательности»), по умолчанию у администратора и главного бухгалтера; есть с 3.0.63.15 (S-30).

## НДС (подробно)

- Помощник по учёту НДС (Отчёты › НДС › Отчётность по НДС) проверяет учёт, формирует регламентные операции, книги,
  декларацию и платёжки; с 3.0.67.67 безусловный перенос вычетов на будущее отключён (S-11; путь 2018 г.
  [проверить]).
- Экспресс-проверка (Отчёты › Анализ учёта) содержит разделы «ведение книги продаж» и «ведение книги покупок»,
  включая сквозную нумерацию СФ (S-14, S-31).
- «Сверка данных учёта НДС» — обмен реестрами СФ с контрагентами через сервис (с 3.0.40), нужен договор с партнёром;
  не путать с актом сверки расчётов (S-32).
- Раздельный учёт входящего НДС — настройка учётной политики с историей изменений; при нём вычет только через
  «Формирование записей книги покупок», как и в особых случаях (авансы, экспорт, ОС) (S-13).

## ЕНС и налоги (подробно)

- Штрафы по ЕНС — 99.01 или 91.02; аналитика в регистрах подсистемы ЕНС (S-9).
- Налог к уменьшению по декларации — «Операция по ЕНС» вид «Налоги (начисление)» со знаком минус; по НДС — только
  после решения ИФНС о возмещении (S-9). Отчёты по регистрам ЕНС — с 3.0.143 (S-33).

## 2026 год (подробно)

- Ставки 0/10/5/7 % остаются; проверять ставку в карточке номенклатуры; тест на рабочей дате 01.01.2026 в
  персональных настройках (S-27).
- Выбор ставки на УСН — в «Налоги и отчёты», сравнение — «Руководителю › Сравнение режимов налогообложения»; перейти
  на 5/7 % можно с начала квартала (S-21, S-25). Учёт НДС на УСН — с 3.0.165, раздел 7 декларации при 5/7 % упрощён
  с 3.0.173 (S-25).
- 3.0.189.29: строка 5б в печатной форме СФ с 01.01.2026, формат УПД 5.03 по умолчанию в ЭДО, статья ДДС «Единый
  налоговый платёж», КБК по приказу Минфина на 2026 (S-34).

## Банк, сверки, запреты (подробно)

- Выписка из файла грузится и при подключённом ДиректБанке (с 3.0.117) — когда банк недоступен или нужен старый
  период; выписки по валютным счетам через ДиректБанк — тоже с 3.0.117 (S-3, S-4).
- Акт сверки в формате ФНС: переключатель «В электронном виде», «Заполнить», провести, «ЭДО › Отправить» (S-10).
- Дата запрета для одного пользователя отдельно — только доработкой (S-26).
- Операция, введённая вручную, не создаёт записей КУДиР при УСН — по форуму [проверить] (S-35).

## Для ревью (подробно)

Раздел «Коротко» идёт в промпт помощника целиком; разделы с пометкой «(подробно)» — справочник для чтения по запросу
(get_instructions_file). Всё своими словами; номера источников — в sources.md (S-n); «опыт» — из работы помощника в
живых базах (2026-10); строки с [проверить] источником не подтверждены и в промпт не идут.
