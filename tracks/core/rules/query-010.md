# Параметр схемы, собранной кодом, надо ставить и в настройках

## Симптом

Схема компоновки строится программно: набор-запрос, `Схема.Параметры.Добавить()` с
заполненным `Значение` для каждого параметра запроса. Настройки — из
`КомпоновщикНастроекКомпоновкиДанных.Инициализировать(...)`. При выводе результата —
«Значение параметра не установлено» по первому же параметру запроса.

## Причина

`Значение` параметра схемы — значение по умолчанию для настроек, а в запрос уходят
параметры данных настроек с включённым использованием. После инициализации компоновщика
элемент параметра в `Настройки.ПараметрыДанных` есть, но не используется.

## Как правильно

После `Инициализировать` пройти параметры схемы и вызвать
`Настройки.ПараметрыДанных.УстановитьЗначениеПараметра(Имя, Значение)` — метод ставит и
значение, и использование. Массив для `В (&Параметр)` — в `СписокЗначений` при
`ДоступенСписокЗначений = Истина` у параметра схемы.
