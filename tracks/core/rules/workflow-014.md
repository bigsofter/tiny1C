# Внешняя обработка из «Дополнительных отчетов и обработок» хранится в данных базы: в выгрузке конфигурации её нет, правят её через файл epf/erf

## Симптом

Задача «добавить колонку в печатную форму документа» не закрывается правкой конфигурации: в выгрузке конфигурации в XML нужного макета нет, поиск по исходникам не находит ни макета, ни функции печати. В меню «Печать» документа форма при этом есть.

Попытка разобрать файл обработки конфигуратором (`/DumpExternalDataProcessorOrReportToFiles`) молча завершается с кодом 1, если у входного файла расширение не epf/erf: в логе только шапка «Входной бинарный файл… Формат: Иерархический», текста ошибки нет.

## Причина

Внешние печатные формы, отчёты и обработки БСП подключаются через справочник ДополнительныеОтчетыИОбработки: файл лежит в элементе справочника (реквизит ХранилищеОбработки типа ХранилищеЗначения), то есть в ДАННЫХ базы. Выгрузка конфигурации в файлы, сравнение конфигураций и загрузка конфигурации его не видят и не меняют.

Конфигуратор решает «обработка или отчёт» по расширению входного файла: файл с другим расширением он не разбирает и выходит с кодом 1 без сообщения.

## Правило

Прежде чем планировать правку печатной формы, отчёта или обработки, проверить, откуда она. Нет её в выгрузке конфигурации, а в «Дополнительных отчетах и обработках» есть элемент с ней — это внешняя обработка, и правится она отдельно от конфигурации:

1. Выгрузить файл из элемента справочника: карточка → «Выгрузить в файл…» в режиме 1С:Предприятие (или программно из ХранилищеОбработки).
2. Сохранять с расширением по виду: печатная форма и обработка — epf, отчёт — erf. С другим расширением `/DumpExternalDataProcessorOrReportToFiles` не работает.
3. Разобрать в XML (`/DumpExternalDataProcessorOrReportToFiles`), поправить макет и модуль, собрать обратно (`/LoadExternalDataProcessorOrReportFromFiles`).
4. Загрузить новую версию в ТОТ ЖЕ элемент справочника («Загрузить из файла…»), а не новым элементом — иначе в документе появится вторая команда печати, а старая останется.

Нет доступа к режиму предприятия и нет готового файла — правку конфигурацией не обещать: запросить у заказчика файл обработки или доступ.

## Как проверить

1. Поиск имени макета или формы по выгрузке конфигурации ничего не дал, а в меню «Печать» документа форма есть — подозревать внешнюю.
2. В режиме предприятия открыть «Администрирование → Печатные формы, отчеты и обработки → Дополнительные отчеты и обработки» и найти элемент по названию формы.
3. После загрузки новой версии сформировать печатную форму из документа и сравнить с прежней: изменилось только то, что правили.

## История

2026-10-11. Задача: добавить в печатные формы отчёта комитенту колонку УИН из серии номенклатуры. Встроенные формы документа поправили в конфигурации (макет и функции печати). Одну форму исполнитель в выгрузке конфигурации не нашёл: она оказалась внешней печатной формой в справочнике «Дополнительные отчеты и обработки».

Первый заход закрылся частично: файла обработки у исполнителя не было. Во втором список внешних обработок базы получили (29 записей), но разбор каждой в XML падал с кодом 1 без текста ошибки. Версии «нет лицензии» и «нет прав на папку» отвергнуты: выгрузка конфигурации той же копии с теми же учётными данными за минуту до этого прошла. Причина — рабочая копия файла называлась cur.bin, а конфигуратор выбирает разбор по расширению; с epf/erf разбор работает.
