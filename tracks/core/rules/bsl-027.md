# СтандартныеРеквизиты.Найти не существует

## Факт

`Метаданные.Документы.X.Реквизиты` — коллекция объектов метаданных с методом `Найти(Имя)`.
`Метаданные.Документы.X.СтандартныеРеквизиты` — другая коллекция (описания стандартных реквизитов):
метода `Найти` у неё нет. Вызов компилируется и падает при выполнении ошибкой вызова метода
контекста — часто глубоко внутри записи объекта, откуда текст выглядит как ошибка `Записать`.

## Правило

Стандартный реквизит искать обходом `Для Каждого … Из СтандартныеРеквизиты` по `Имя`, а лучше —
не искать вовсе: у стандартных реквизитов (`Номер`, `Дата`, `ПометкаУдаления`) тип известен заранее.

## Как проверить

Поиск `СтандартныеРеквизиты.Найти(` по модулям; сценарий, проходящий ветку со стандартным реквизитом.
