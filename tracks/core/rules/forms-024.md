# Планировщик: перенос ленты и положение шкалы

## Симптом

Поле «Планировщик» с измерением (например, станки) рисует ленту по суткам: каждый день —
отдельный блок, шкала времени вертикально слева, значения измерения — подколонками
дня. Для загрузки ресурсов на неделю это нечитаемо.

## Причина

Умолчание планировщика — периодический вариант с единицей «день». Отключить перенос
кратностью 0 нельзя: `Планировщик.КратностьПериодическогоВарианта = 0` падает при
открытии формы «Ошибка установки значения атрибута контекста».

## Как править

Единицу переноса задать на весь период отображения, шкалу — сверху:
`ЕдиницаПериодическогоВарианта = ТипЕдиницыШкалыВремени.Неделя`,
`КратностьПериодическогоВарианта = 1`, `ШкалаВремени.Положение = ПоложениеШкалыВремени.Верх`.

## Заметки

Реквизит формы типа «Планировщик» собирается в EDT без внешнего файла настроек `.pnrs`:
выгрузка даёт `pl:Planner` с пустыми настройками, база загружается.
