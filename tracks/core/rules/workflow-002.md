# Отчёты 1С пишутся с BOM - якорь ^ в grep теряет первую строку

## Симптом

Скрипт «не видит» первую строку файла-отчёта 1С, интерактивно grep её находит.

## Причина

1С пишет текстовые файлы с BOM (EF BB BF). `grep '^МАРКЕР'` не совпадает на первой
строке: перед маркером стоит BOM. Интерактивный ugrep BOM пропускает, /usr/bin/grep
- нет.

## Правило

В скриптах, разбирающих файлы 1С, не использовать якорь `^` для маркеров
(`grep 'ОШИБКА;'` вместо `grep '^ОШИБКА;'`) либо срезать BOM явно.
