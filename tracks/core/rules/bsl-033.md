# Родитель в иерархическом справочнике - только группа

## Симптом

`Объект.Родитель = ...` падает: «Значение поля "Группа" должно быть группой».

## Причина

В справочнике с иерархией групп и элементов родителем может быть только группа. Во внешних
данных ссылка на «родителя» легко указывает на обычный элемент.

## Правило

Перед присваиванием `Родитель` проверять `ЭтоГруппа` у предполагаемого родителя. Если это не
группа, элемент класть в корень и писать строку в протокол загрузки.

```bsl
Если ЗначениеЗаполнено(Кандидат) И Кандидат.ЭтоГруппа Тогда
    Объект.Родитель = Кандидат;
Иначе
    Протокол.Добавить("Родитель не группа: " + Строка(Кандидат));
КонецЕсли;
```

См. mdo-008: у справочника без свойства иерархии поля `Родитель` и `ЭтоГруппа` нет вовсе.

## История

2026-09-17, загрузка справочников в базу на 1С:УНФ: родитель по данным оказался элементом,
запись упала; решением стали размещение элемента в корне и строка в протоколе загрузки.
