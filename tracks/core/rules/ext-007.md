# Роль из DefaultRoles расширения не получает права на заимствованные объекты

## Симптом

`UpdateDBCfg -Extension` падает: «Назначение прав доступа на заимствованные объекты
основными ролями в расширениях недопустимо».

## Причина

Роль, указанная в `DefaultRoles` расширения, считается основной. Права на объекты
основной конфигурации (заимствованные) такая роль иметь не может.

## Правило

- Права на заимствованные объекты выдавать отдельной ролью, не входящей в `DefaultRoles`,
  либо работать в привилегированном режиме.
- Основная роль расширения несёт только права на собственные объекты расширения (для
  начала достаточно минимального `Rights.xml`: запуск клиента и объекты расширения).

## Как проверить

`UpdateDBCfg -Extension` после загрузки; код 0.

## История

2026-09, проект на 1С:УНФ: основная роль расширения получила права на заимствованные
объекты, обновление базы остановилось на этой ошибке.
