# Рисунок в строке области: искать перебором, сбрасывать на каждой строке, в результате не искать по имени

## Симптом

Форма с картинкой в каждой строке таблицы (фото товара) падает «Метод объекта не обнаружен (Найти)»
на `Область.Рисунки.Найти(Имя)`. После исправления строка без картинки печатается с картинкой
предыдущей строки, а проверка готового документа по имени рисунка находит ноль картинок, хотя они
напечатаны.

## Причина

- У коллекции `Рисунки` табличного документа на 8.5.1 нет метода `Найти` — только перебор и индекс.
- Область строки получают один раз и выводят в цикле: присвоенная рисунку картинка остаётся в
  области до следующего присвоения.
- При выводе нескольких областей с одноимённым рисунком платформа переименовывает рисунки в
  результате (в пробе: `D1` и `ФотоСтроки`) — имя из макета в готовом документе не уникально и не
  стабильно.

## Как править

- Рисунок области находить перебором `Для Каждого ... Из Область.Рисунки` по `Имя`.
- На каждой строке присваивать картинку явно, а при отсутствии данных — `Новый Картинка` (пустую).
- Готовый документ проверять не по имени рисунка, а по числу непустых картинок
  (`ТипРисунка = Картинка` и `Картинка.Вид <> ВидКартинки.Пустая`), например разницей формы с
  картинками и без.

## История

maERP 2026-10-12, 2.0.16.74: строка запроса котировок с фото товара. Первый прогон тестов упал на
`Рисунки.Найти`; после перебора тест по имени `ФотоСтроки` находил 0 фото — проба внешней обработкой
показала переименование при выводе.
