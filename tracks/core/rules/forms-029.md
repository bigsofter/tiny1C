# Что внутри Form.bin

Справка, составлена по измерению одного файла. Для других форм и версий платформы раскладка не
проверялась. Править бинарный контейнер руками не рекомендуется: штатный путь - forms-028 (модуль
отдельным файлом, сборка вшивает его сама).

- `Forms/<Форма>/Ext/Form.bin` - контейнер с двумя файлами: `form` (описание элементов, команд и
  реквизитов) и `module` (текст модуля формы в UTF-8 с BOM).
- Раскладка в разобранном файле: 16-байтовый заголовок, далее блоки. Заголовок блока - перевод
  строки, три восьмизначных шестнадцатеричных числа через пробел (размер данных, размер блока,
  адрес следующего блока), снова перевод строки. Первый блок - корневой дескриптор, по 12 байт на
  файл (адрес записи имени, первый блок данных, ещё одно поле); запись имени - 8 + 8 байт времени,
  4 байта признака и имя в UTF-16LE. Смысл последнего поля дескриптора не уточнялся.
- В этом файле блок `form` лежал последним.
- Событие «При открытии» хранится в описании формы: у формы без назначенных событий там `{0}`,
  и `Процедура ПриОткрытии` не вызывается (тихий запуск с параметром `/C` не срабатывает).

## Как проверить

Выгрузка обработки обратно после любых действий с контейнером: текст модуля и набор строк
описания формы должны совпасть. Только глазами и выгрузкой.
