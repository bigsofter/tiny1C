# В модуле формы метод с директивой &НаКлиентеНаСервере не виден ни клиенту, ни серверу

## Симптом

BSL LS и сверки молчат, EDT может не подсветить. Проверка конфигурации
(`DESIGNER /CheckConfig`, шаг 1 `scripts/smoke.sh`) даёт ошибку компиляции
на каждом вызове:

```
{Обработка.АРМПроизводство.Форма.Форма.Форма(806,27)}: Процедура или функция с указанным именем не определена (ПраваВводаСтрок)
{Обработка.АРМПроизводство.Форма.Форма.Форма(1384,10)}: Процедура или функция с указанным именем не определена (ПраваВводаСтрок)
```

Форма с таким модулем не открывается.

## Причина

Директива `&НаКлиентеНаСервере` (метод с контекстом формы на обеих сторонах)
в модуле управляемой формы 8.5.1 не компилируется как метод формы: вызов из
`&НаСервере` и из `&НаКлиенте` не находит его. Для кода, общего клиенту и
серверу формы, есть только `&НаКлиентеНаСервереБезКонтекста` — реквизиты формы
тогда передаются параметром.

## Правило

Общий клиенту и серверу метод формы объявлять `&НаКлиентеНаСервереБезКонтекста`
и передавать форму параметром.

Неправильно:

```bsl
&НаКлиентеНаСервере
Функция ПраваВводаСтрок()
	Возврат Новый Структура("Выпуски", МожноВводитьВыпуски);
КонецФункции
```

Правильно:

```bsl
&НаКлиентеНаСервереБезКонтекста
Функция ПраваВводаСтрок(Форма)
	Возврат Новый Структура("Выпуски", Форма.МожноВводитьВыпуски);
КонецФункции
// вызов: ПраваВводаСтрок(ЭтотОбъект)
```

## Как проверить

`grep -rn "^&НаКлиентеНаСервере$" --include=Module.bsl src/cf/src/*/*/Forms src/cf/src/CommonForms` —
находок быть не должно. Надёжная проверка — CheckConfig копии базы после
загрузки модуля.

## История

2026-09-15, maERP, E12.3a (2.0.15.33). Права ввода строк четырёх нижних
таблиц рабочего места собрали в функцию формы с контекстом на обеих сторонах.
Сценарии уровня 3 прошли (форму они не компилируют), CheckConfig копии базы
отказал; функция переделана без контекста с параметром `Форма`, как
`ПрименитьСостояниеПанели(Форма)` той же формы.
