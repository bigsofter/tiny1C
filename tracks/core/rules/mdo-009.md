# Блок .mdo, сгенерированный один раз и вставленный в несколько объектов, несёт одинаковые uuid

## Симптом

Один и тот же реквизит (например, `ВидОперации`) добавлен скриптом в три документа —
у всех трёх одинаковый `uuid`. Линтер, refcheck, выгрузка EDT в XML и загрузка в
базу сборки молчат. Дальше возможны отказ загрузки, молчаливая перегенерация uuid
при Refresh в EDT (и другие идентификаторы в следующей поставке) или неверное
сопоставление полей при реструктуризации у клиента.

## Причина

Скрипт строит текст блока (`<attributes uuid="...">`) с `uuid.uuid4()` один раз и
вставляет одну строку в цикле по объектам. Генератор вызывается при построении
текста, а не при каждой вставке.

## Как править

Строить блок функцией, вызываемой на каждый объект, — новый uuid на каждую вставку.
После любой скриптовой правки .mdo прогонять поиск повторов uuid по всему проекту.
Повтор, найденный после выпуска CFU, исправлять нельзя без последствий — ловить до
первого импорта в EDT.
