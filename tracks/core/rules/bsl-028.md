# Локальная переменная не может называться как свойство глобального контекста

## Факт

`Документы`, `Справочники`, `Метаданные`, `Константы`, `РегистрыНакопления` и другие менеджеры — свойства
глобального контекста, доступные только для чтения. Строка `Документы = Запрос.Выполнить().Выгрузить();`
компилируется: синтаксический контроль и BSL LS её не останавливают, а при выполнении платформа пытается
записать свойство контекста и падает «Поле объекта недоступно для записи (Документы)». Ветка, где стоит
присваивание, часто редкая (удаление, отказ) — ошибка доживает до пользователя.

## Правило

Локальным переменным давать имена с уточнением: `ДокументыСклада`, `Оформляющие`, `ДокументыСписка`. Имя
коллекции метаданных в роли переменной не использовать никогда, даже в маленькой функции.

## Расширенный список и что в него не входит

Прогоном подтверждено только присваивание `Документы`. Список ниже составлен по составу глобального
контекста (коллекции и менеджеры, доступные только для чтения), а не отдельными прогонами:
`ПланыОбмена`, `ЖурналыДокументов`, `Последовательности`, `КритерииОтбора`,
`ВнешниеИсточникиДанных`, `ХранилищаНастроек`, `ПараметрыСеанса`, `Метаданные`. То же относится к
переменной цикла `Для Каждого` и параметру метода: источник включал их в запрет, прогоном они
не проверялись. `Пользователи` в БСП - общий модуль, а не свойство платформы (см. bsl-011), и
в этот список не входит.

Имена типов и функций, наоборот, затеняются законно: `Запрос = Новый Запрос;`,
`Соответствие = Новый Соответствие;`, `Структура`, `Массив`, `ТаблицаЗначений`, `Файл`,
`Для Каждого Строка Из ...` работают в боевых модулях (проверено чтением работающего кода). Не
вносить их в стоп-лист: ложная тревога заставит править рабочий код.

## Как проверить

Поиск присваиваний `^\s*(Документы|Справочники|Метаданные|…) = ` по изменённым модулям до передачи на базу;
сценарий, проходящий ветку, — исключение при выполнении.

## История

2026-09-25, выгрузчик платежей проекта на 1С: `Документы = Таблица...;` упало в боевом прогоне
«Поле объекта недоступно для записи (Документы)»; сборка и статические проверки ошибку не видели.
