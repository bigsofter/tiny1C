# Поле отбора, одноимённое с измерением регистра пакета, — вычисляемым полем

## Симптом

Набор СКД — пакет: продажи (`Продажи.Обороты`, измерение `МестоХранения`) во временную
таблицу, затем объединение с остатками другого регистра. Итоговое поле `МестоХранения`
выбирается из обеих веток. Без отбора и с группировкой по `МестоХранения` строки верны,
отбор `МестоХранения = <склад>` по складу, который есть только в ветке остатков (продаж
по нему не было), даёт пустой результат. Отбор по полю `ТорговаяТочка` — то же выражение
под другим именем — возвращает строку верно. Полное соединение вместо объединения и
обёртка всего объединения во вложенный запрос симптом не меняют.

## Причина

СКД разбирает поле отбора по имени по всему пакету и накладывает условие не только на
итоговую выборку. Точная точка (параметры виртуальной таблицы, временная таблица) в
maERP не локализована; поле с именем, которого нет среди измерений регистров пакета,
отбирается верно.

## Как правильно

Поле, по которому отбирает вариант и которое совпадает по имени с измерением регистров
пакета, не выбирать в запросе, а объявить `calculatedField` схемы с выражением от поля
другого имени (`МестоХранения` = `ТорговаяТочка`). Вычисляемое поле СКД отбирает по
готовому результату. Сценарий уровня 3 — с отбором на значении, которое есть только в
одной ветке пакета.
