# Пустая строка внутри текста запроса - четыре кавычки

## Симптом

Прогон падает «Строка, не закрывающаяся кавычкой» с указанием позиции в тексте запроса.
Модуль при этом компилируется, сборка внешней обработки проходит, сверка полей запроса с
метаданными тоже чиста.

## Причина

Текст запроса - строковый литерал BSL, а кавычка внутри литерала удваивается. Запись `&П = ""`
превращается в `&П = "` (одиночная кавычка в тексте запроса), и литерал запроса оказывается
открытым. Сверка полей разбирает уже испорченный текст.

## Правило

```bsl
// НЕПРАВИЛЬНО
|ГДЕ Документ.Комментарий = ""
// ПРАВИЛЬНО: в запросе пустая строка, в BSL-литерале - четыре кавычки
|ГДЕ Документ.Комментарий = """"
```

Ловится счётом: в строках текста запроса число кавычек кратно четырём, а у последней строки
литерала даёт остаток один (закрывающая).

## История

2026-09-25, выгрузчик заказов: параметр с пустой строкой в тексте запроса остановил боевой
прогон. Сборка внешней обработки и сверка полей запроса ошибки не видели.
