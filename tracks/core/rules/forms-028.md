# Обычная форма: Form.bin делает только Конфигуратор

## Симптом

`Forms/<Форма>.xml` с `<FormType>Ordinary</FormType>` принимается сборкой без ошибки, но
`Ext/Form.bin` не создаётся: `.epf` получается без формы.

## Причина

Обычная форма хранится бинарно (см. forms-029), а описание в XML для неё платформа не разбирает.

## Правило

- Обычную форму делает только Конфигуратор. В исходниках держать снятый из `.epf` `Form.bin`,
  а модуль - отдельным файлом `Forms/<Форма>/Ext/Form/Module.bsl`; сборка вшивает его в контейнер.
- Сборка из файлов принимает `Form.bin`, но каждый раз пересобирает контейнер: метки времени,
  идентификаторы элементов и счётчик версии формы меняются. Побайтная сверка исходника и выгрузки
  невозможна, сверять текст модуля и набор строк описания формы.
- Если модуль вшивается сборкой, правка модуля в Конфигураторе затрётся следующей сборкой:
  править исходник, а в Конфигураторе менять только элементы формы.

## История

2026-09-24, обработка для УТ 10. XML-форма Ordinary дала `.epf` без формы; рабочей оказалась схема
с `Form.bin` из `.epf` и отдельным модулем.
