# Составной тип: «пустой» реквизит может нести конкретный тип

## Симптом

В выгрузке у записей с незаполненным реквизитом составного типа стоит признак типа
(например ссылка на справочник типов цен) при отсутствующем значении.

## Причина

Незаполненный составной реквизит по умолчанию равен `Неопределено`. Конкретный тип `ТипЗнч`
возвращает, когда в реквизит записана пустая ссылка этого типа. В наблюдении реквизит
выглядел пустым, а `ТипЗнч` давал конкретный тип справочника; откуда взялась пустая ссылка
этого типа, не установлено.

## Правило

Перед разбором типа значения проверять `ЗначениеЗаполнено(Значение)`; для пустого составного
реквизита не писать ни тип, ни значение.

```bsl
// НЕПРАВИЛЬНО
Тип = ТипЗнч(Строка.ТипЦен);
// ПРАВИЛЬНО
Если ЗначениеЗаполнено(Строка.ТипЦен) Тогда
    Тип = ТипЗнч(Строка.ТипЦен);
КонецЕсли;
```

## Как проверить

Выгрузка записей с пустым составным реквизитом: в файле не должно быть типа без значения.
Поиск `ТипЗнч(` по составным реквизитам без `ЗначениеЗаполнено` выше - глазами.

## История

2026-09-18, выгрузка из УТ 10: 25774 записи несли тип без значения; в заметке источника
рекомендовано проверять заполненность перед разбором типа.
