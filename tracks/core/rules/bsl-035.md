# Составной тип: пустая ссылка всё равно несёт конкретный тип

## Симптом

В выгрузке у записей с незаполненным реквизитом составного типа стоит признак типа
(например ссылка на справочник типов цен) при отсутствующем значении.

## Причина

У незаполненного реквизита составного типа платформа хранит идентификатор одного из типов,
поэтому `ТипЗнч(Реквизит)` возвращает конкретный тип, хотя значения нет.

## Правило

Перед разбором типа значения проверять `ЗначениеЗаполнено(Значение)`; для пустого составного
реквизита не писать ни тип, ни значение.

```bsl
// НЕПРАВИЛЬНО
Тип = ТипЗнч(Строка.ТипЦен);
// ПРАВИЛЬНО
Если ЗначениеЗаполнено(Строка.ТипЦен) Тогда
    Тип = ТипЗнч(Строка.ТипЦен);
КонецЕсли;
```

## История

2026-09-18, выгрузка из УТ 10: 25774 записи несли тип без значения, проверка
заполненности перед разбором типа это устранила.
