# Файл расширения .cfe

## Симптом

Собранный вручную ZIP-контейнер платформа отвергает: «Неверный формат» или «Ожидается файл
расширения».

## Правило

- `.cfe` создаёт только платформа: `DESIGNER /DumpCfg <файл>.cfe -Extension "<Имя>"` из уже
  загруженного расширения либо сохранение из Конфигуратора.
- Загрузка файла: `DESIGNER /LoadCfg "<файл>.cfe" -Extension "<Имя>"`, затем применение
  `/UpdateDBCfg -Extension "<Имя>"` отдельной командой. Тела модулей и схемы форм при этом
  сохраняются.
- После `LoadCfg` расширение, как и при загрузке из файлов, неактивно (см. ext-004).

## История

2026-09-17 и 2026-10-12. Из загруженного расширения `DumpCfg` собрал `.cfe` (8 КБ для
небольшого тестового расширения и около 24 МБ для большого рабочего). Ручная сборка ZIP не
принята платформой.
