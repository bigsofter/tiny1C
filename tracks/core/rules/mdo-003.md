# DateTime - не тип в .mdo; проверка типов реквизитов

## Правило

В .mdo EDT тип даты - `Date` с квалификаторами (`<dateQualifiers>`), типа `DateTime`
не существует. Заводя реквизиты правкой XML, сверять написание типов с существующим
реквизитом такого же типа в этой же конфигурации, а не писать по памяти.
