# При загрузке данных проведение запрещено, а типовое заполнение отключено

## Симптом

`Объект.Записать(РежимЗаписиДокумента.Проведение)` при включённом `ОбменДанными.Загрузка`
падает: «Действие не может выполняться в режиме загрузки данных». Типовые обработчики
при этом флаге не заполняют обязательные реквизиты - объект ложится пустым.

## Причина

Флаг загрузки включает режим, в котором проведение запрещено. Типовые `ПередЗаписью` и
`ОбработкаПроверкиЗаполнения` в конфигурациях проверяют флаг и сразу выходят, поэтому
реквизиты, которые они обычно подставляют, остаются незаполненными.

## Правило

1. Проведение - вторым проходом: сначала запись с `ОбменДанными.Загрузка = Истина`
   режимом `Запись`, затем отдельно `Загрузка = Ложь` и `Записать(РежимЗаписиДокумента.Проведение)`.
2. Реквизиты, которые в обычном режиме подставляет типовой код (страна регистрации,
   юридическое или физическое лицо, головной контрагент, признак «сумма включает НДС» и
   подобные), при загрузке заполнять явно в своём коде.

```bsl
// НЕПРАВИЛЬНО
Объект.ОбменДанными.Загрузка = Истина;
Объект.Записать(РежимЗаписиДокумента.Проведение);
// ПРАВИЛЬНО: проход 1
Объект.ОбменДанными.Загрузка = Истина;
Объект.Записать(РежимЗаписиДокумента.Запись);
// проход 2, отдельный вызов
Объект.ОбменДанными.Загрузка = Ложь;
Объект.Записать(РежимЗаписиДокумента.Проведение);
```

## Как проверить

Загрузка на копии базы: сравнить число документов, записанных и проведённых после обоих проходов.

## История

2026-09-24, перенос документов УТ 10 в БП. 6522 документа с признаком «проведён» дали
именно эту ошибку, 521 непроведённый документ, записанный тем же кодом режимом
`Запись`, записался без ошибок: разница только в режиме записи. Вторая часть правила
(пустые обязательные реквизиты при загрузке) - наблюдение из той же работы, отдельным
прогоном с датой не фиксировалась.
