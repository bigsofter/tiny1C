# Своя команда объекта показывается в панели раздела рядом со стандартной — дубль пункта меню

## Симптом

В панели раздела один пункт дважды с одинаковым названием («Драйверы оборудования» ×2),
либо пункт стоит первым в группе вопреки порядку из `.cmi`, либо появился пункт,
который в `.cmi` вроде бы скрыт.

## Причина

У объекта, кроме стандартных команд (`StandardCommand.OpenList`, `StandardCommand.Open`),
есть своя команда в `.mdo` (`<commands>` с группой `NavigationPanelOrdinary` /
`NavigationPanelImportant`). В `.cmi` подсистемы видимость и порядок заданы только для
стандартной, а своя команда получает видимость по умолчанию и встаёт вне заданного
порядка — обычно первой в группе. Синонимы у них, как правило, одинаковые, и на клиенте
это выглядит дублем.

```xml
<!-- .mdo объекта: своя команда навигации -->
<commands uuid="...">
  <name>ОткрытьДрайверыОборудования</name>
  <group>NavigationPanelOrdinary</group>
</commands>

<!-- .cmi подсистемы: решить, кто из двух виден -->
<visibilityFragments>
  <command>Catalog.ДрайверыОборудования.Command.ОткрытьДрайверыОборудования</command>
  <visible><common>true</common></visible>
</visibilityFragments>
<visibilityFragments>
  <command>Catalog.ДрайверыОборудования.StandardCommand.OpenList</command>
  <visible/>
</visibilityFragments>
```

Своя команда обычно существует не зря (открывает форму с отбором по рабочему месту,
через менеджер подсистемы) — оставлять её, а скрывать стандартную.

## Как проверить

Для каждого объекта из `<content>` подсистемы: `grep -A25 "<commands " <объект>.mdo`
и посмотреть `<group>`. Команды `NavigationPanel*` — в `.cmi` явно, с видимостью
и порядком. Команды с `commandParameterType` (параметризуемые) в панель раздела не
попадают, их трогать не нужно.

## История

maERP 2026-09-08, раздел «Настройка» после переделки меню: «Регламентные и фоновые
задания» стояли первыми в группе «Настройки программы» (своя команда обработки не
скрыта), «Драйверы оборудования» показывались дважды (своя и стандартная), «Подключаемое
оборудование» — сверху раздела и в группе (объект в двух подсистемах). Исправлено
в 2.0.14.22.
