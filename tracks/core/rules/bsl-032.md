# ПланыСчетов.НайтиПоКоду: второй параметр не булев

## Симптом

`ПланыСчетов.<ИмяПлана>.НайтиПоКоду(Код, Ложь)` падает: «Несоответствие типов (параметр
номер '2')».

## Причина

У менеджера плана счетов второй параметр метода не принимает булево значение. Какой тип он
принимает, по документации не сверено: в индексе API платформы метод найти не удалось. У
справочников `Справочники.<Имя>.НайтиПоКоду(Код, Ложь)` в работе того же проекта выполнялся без
ошибок (валюта находилась по коду): не переписывать его без повода.

## Правило

Для плана счетов искать счёт запросом, а не угадывать сигнатуру:

```bsl
// НЕПРАВИЛЬНО
Счет = ПланыСчетов.<ИмяПлана>.НайтиПоКоду(Код, Ложь);
// ПРАВИЛЬНО
Запрос.Текст = "ВЫБРАТЬ ПЕРВЫЕ 2 Счета.Ссылка ИЗ ПланСчетов.<ИмяПлана> КАК Счета ГДЕ Счета.Код = &Код";
```

## Как проверить

Поиск по модулям вызовов `ПланыСчетов.<Имя>.НайтиПоКоду(` с двумя параметрами; прогон на копии
базы. Компилятор вызов пропускает - ловится только при выполнении.

## История

Дата взята по разделу источника (2026-09-24), у самой записи даты нет. Перенос данных в БП
обработкой: вызов с булевым вторым параметром упал в боевом прогоне; в индексе API платформы
метод не нашёлся, сверка «по справке» не помогла.
