# Переписывая CommandInterface.cmi целиком, перенеси ролевые фрагменты видимости

## Симптом

После перестройки раздела (объекты переехали между подсистемами, `.cmi` переписаны с явной
видимостью каждой команды) у роли, которой раньше список был скрыт, он появился в меню. Проверка
конфигурации, сверка меню по файлам и тесты молчат: видимость по ролям они не моделируют.

## Причина

Фрагмент видимости в `.cmi` может быть не только общим, но и ролевым:

```xml
<visible>
  <common>true</common>
  <for>
    <role>Role.Кассир</role>
  </for>
</visible>
```

`<for>` без `<value>` означает `false` для этой роли. Фрагмент живёт в `.cmi` той подсистемы, где
лежит команда. Когда объект уходит в другую подсистему, а её `.cmi` пишется заново по списку «что
показать, что скрыть», ролевое исключение теряется: новая подсистема показывает команду всем.

## Правило

1. До переписывания `.cmi` найти ролевые фрагменты в подсистемах, откуда уходят объекты:
   `git grep -n '<role>' -- '*.cmi'`.
2. Перенести каждый фрагмент в `.cmi` подсистемы, куда уходит команда, один в один; генератор `.cmi`,
   если он есть, должен уметь писать `<for><role>`.
3. Снять исключение можно только осознанно — решением в плане и строкой в «кто что получает».
4. Пустой безымянный фрагмент (`<visibilityFragments><visible/></visibilityFragments>` без `<command>`)
   при переписывании выбросить — он ни к чему не относится.

## Как проверить

Машинной проверки нет. Перед коммитом — `git grep '<role>'` по старой и новой версии `.cmi` раздела
(`git show HEAD:<путь>`), число ролевых фрагментов по каждой команде совпадает или расхождение
записано в плане. После обновления базы — меню под этими ролями.

## История

2026-10-03, maERP, этап 3 перестройки меню. Документы продаж переехали из группы «Работа с
покупателями» в корень раздела, `.cmi` всех групп писались генератором с явной видимостью. В старом
`.cmi` список реализаций был скрыт у кассира и закупщика, возвратов — у кассира. Гейт плана поймал
потерю по рабочему дереву до коммита; генератор научили писать ролевые фрагменты.
