# Configuration.xml расширения и маркеры заимствования

Справка. Формат - выгрузка Конфигуратора. Имена в примерах вымышленные.

## Configuration.xml

- `ObjectBelonging=Adopted` и `ConfigurationExtensionPurpose=Customization` (расширение-доработка).
- `NamePrefix` - префикс имён собственных объектов расширения (например `Доп_`),
  `KeepMappingToExtendedConfigurationObjectsByIDs=true`, `ConfigurationExtensionCompatibilityMode`
  (см. ext-005).
- `ChildObjects` - плоский список `<Тип>Имя</Тип>`, заимствованные и собственные вперемешку.

## Заимствованный или собственный

Признак заимствования - у элемента (не только объекта):
`<ObjectBelonging>Adopted</ObjectBelonging>`, `<ExtendedConfigurationObject>uuid</ExtendedConfigurationObject>`
и пустой `<InternalInfo/>`, плюс усечённый набор свойств. Собственный реквизит расширения
(`Доп_*`) этих маркеров не несёт, зато имеет полный набор свойств и `Synonym`.

- Нетронутый заимствованный объект - тонкая обёртка: шапка, `InternalInfo` и заимствованные
  реквизиты, без форм, табличных частей и команд. Принадлежность в `ChildObjects` объекта
  не видна, только по маркерам внутри элементов.
- Заимствованная табличная часть: `ObjectBelonging=Adopted`, `ExtendedConfigurationObject` и
  пустой `<ChildObjects/>`. «Добавлена расширением или заимствована» по XML не определить,
  сверять с базовой конфигурацией.
- Собственная роль: минимальный `Ext/Rights.xml` с объектом `Configuration.<Имя>` (права
  запуска клиентов, `setForNewObjects`, `setForAttributesByDefault`), объектных прав нет.
  Заимствованная роль - обёртка со статусом `Extended` без файла прав (почему права на
  заимствованные объекты в основной роли нельзя - см. ext-007).
- Макет: в разобранном образце заимствованный макет - обёртка без тела: запись объявлена в
  манифесте, файла тела в выгрузке нет. Общий модуль образца был пуст, и файла тела у него
  тоже не было. Это свойство образца, а не общее утверждение: собственный модуль с текстом при
  загрузке из файлов переносился и был виден в выгрузке (см. ext-002).

## Как проверить

На выгрузке своего расширения: маркеры заимствования и состав файлов сверяются с описанием выше.
