# Элемент Form.form без visible скрыт: вставка скриптом без него даёт пустую форму

## Симптом

Форма открывается без ошибок: заголовок на месте, командная панель формы с кнопкой
«Создать» есть, а рабочая область пустая — ни таблицы, ни закладок, ни полей.
Проверка конфигурации, BSL LS, смок «открыть все формы» и сценарные тесты на данных
зелёные. Код `ПриСозданииНаСервере` выполнился: заголовок, который он ставит, виден.

## Причина

В XML формы EDT свойство видимости по умолчанию ложно. Поэтому EDT пишет
`<visible>true</visible>`, `<enabled>true</enabled>` и `<userVisible><common>true</common></userVisible>`
у каждого видимого элемента явно, а у намеренно скрытого (скрытые колонки `Код`,
`Ссылка`, служебные поля) просто опускает тег. Узел, вставленный скриптом без этих
тегов, импортируется без замечаний и становится невидимым. Если это корневая группа
или все страницы `Pages`, скрывается всё содержимое формы.

Смок через `ПолучитьФорму` создаёт форму на сервере, но не отрисовывает её —
пустоту он не видит.

## Правило

1. Новый узел `items` копировать с работающего элемента того же вида в этой же
   конфигурации целиком: `visible`, `enabled`, `userVisible`, `extendedTooltip` и
   порядок тегов (урок workflow-005).
2. После правки скриптом сверить новые элементы: у каждого без `<visible>` должна быть
   причина быть скрытым.
3. Булевы свойства — только `true`/`false`: значение вроде `<showTitle>auto</showTitle>`
   у `PageGroupExtInfo` EDT тоже принимает молча.

Неправильно (закладка из скрипта):

```xml
<items xsi:type="form:FormGroup">
  <name>СтраницаЗаказы</name>
  <id>701</id>
  <title>…</title>
  <items>…</items>
  <type>Page</type>
```

Правильно:

```xml
<items xsi:type="form:FormGroup">
  <name>СтраницаЗаказы</name>
  <id>701</id>
  <title>…</title>
  <visible>true</visible>
  <enabled>true</enabled>
  <userVisible>
    <common>true</common>
  </userVisible>
  <extendedTooltip>…</extendedTooltip>
  <items>…</items>
  <type>Page</type>
```

## Как проверить

Скриптом по дереву формы: элементы без `<visible>` среди добавленных диффом. Сам
дефект виден только на клиенте — открыть форму после импорта.

## История

2026-09-13, maERP. В форму списка заказов покупателя скриптом добавили закладки
«Заказы» и «Коммерческие предложения» — без `visible`/`enabled`/`userVisible`.
Список открывался пустым, в том числе новой командой раздела. Первая версия
(подмена формы в `ОбработкаПолученияФормы` по роли без `ВыбраннаяФорма`) была
отвергнута по скриншоту: на нём стоял заголовок, который ставит `ПриСозданииНаСервере`
именно этой формы. Сравнение с работающей формой, где закладки собраны в EDT,
показало отсутствие тегов; замер по конфигурации — 86 форм, где элементы без
`visible` скрыты намеренно. После добавления тегов владелец подтвердил, что форма
отрисовывается.
