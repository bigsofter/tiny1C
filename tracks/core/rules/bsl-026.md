# Номер фиксированной длины приходит с пробелами

## Факт

У документа с длиной номера «Фиксированная» (в .mdo нет `numberAllowedLength Variable`) платформа
хранит номер дополненным пробелами до длины: «ТКП-811131» при длине 11 читается как «ТКП-811131 ».
У документа с переменной длиной — без пробелов. Представление ссылки (`Строка(Ссылка)`) номер
выводит без хвостовых пробелов.

## Чем ломается

- Код, который переносит номер одного документа в другой и сравнивает «что должно быть» с «что
  записано», видит отличие всегда и переписывает объект на каждом вызове — лишние записи, новые
  версии данных, блокировки.
- Тест, который собирает ожидаемое представление из `Документ.Номер`, получает лишний пробел перед
  «от»/«de» там, где номер короче длины.

## Правило

Номера документов сравнивать и склеивать через `СокрЛП(Номер)`. Переносимый номер записывать как
есть — дополнение платформа сделает сама.

## Как проверить

Сценарий с номером короче длины: повторная запись без изменений не меняет `ВерсияДанных`.
