# Исходники расширения сверять с выгрузкой из базы

## Симптом

После загрузки стороннего расширения из дерева исходников выгрузка обратно отличается от дерева
в десятках файлов форм (в наблюдении - 74), хотя поведение форм не менялось.

## Причина

Наблюдение: в выгрузке из базы у групп есть `<Behavior>Usual</Behavior>`, у кнопок по умолчанию -
`<ButtonImportance>Main</ButtonImportance>`, а в исходниках стороннего расширения этих свойств
нет. Загрузка таких исходников давала шум в сравнении выгрузки с деревом. Почему они
различаются (например, другая версия платформы или формата у автора исходников), не
установлено и не проверялось.

## Правило

Перед `LoadConfigFromFiles -Extension` сравнить исходники форм с выгрузкой расширения
`DumpConfigToFiles -Extension` из базы, куда грузим; по источнику разумно взять формы из
выгрузки и накладывать на них свои правки. Формат - выгрузка Конфигуратора.

Формы и права, взятые из дампа другой базы, на другой базе не проверялись: не полагаться
на них без выгрузки обратно.

## Как проверить

Выгрузить расширение из базы и сравнить файлы форм с деревом исходников: различаются ли
только перечисленными свойствами. После загрузки - выгрузка обратно и сверка.

## История

2026-10-13: в стороннем расширении таких файлов оказалось 74. Загрузка его исходников
давала шум в сравнении; поведение форм при этом не менялось. Совет брать формы из выгрузки
базы взят из того же разбора и отдельным прогоном не проверялся.
