# Строка() - представление, а не сериализация

## Симптом

1. В файле выгрузки `sum="5 486"` (разделитель групп - неразрывный пробел `Символ(160)`),
   `ЧислоИзСтроки` такое не разбирает.
2. Вместо имени значения перечисления в файле «5%».
3. Вместо `Документ.ЗаказПокупателя` - «Заказ покупателя».

## Причина

`Строка(Значение)` возвращает представление для пользователя: у числа с разделителями
групп разрядов, у перечисления - синоним значения, у типа - представление типа.

## Правило

- Значение в обмен: `XMLСтрока(Значение)` (имена значений перечислений, число без групп).
  На приёме терпеть оба вида записи.
- Имя типа или объекта: `Ссылка.Метаданные().ПолноеИмя()`, не `Строка(ТипЗнч(Ссылка))`.

```bsl
// НЕПРАВИЛЬНО
Атрибут = Строка(Сумма);
Тип = Строка(ТипЗнч(Ссылка));
// ПРАВИЛЬНО
Атрибут = XMLСтрока(Сумма);
Тип = Ссылка.Метаданные().ПолноеИмя();
```

## История

2026-09-24, перенос УТ 10 в БП: сразу 27385 числовых атрибутов в 7 файлах выгрузки были
записаны с разделителями групп. Имя типа через представление проверено боевым
прогоном выгрузчика в УТ 10.3.12.3 (обычное приложение, совместимость 8.2.13).
