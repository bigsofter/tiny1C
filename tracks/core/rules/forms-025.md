# Копия таблицы: дополнения переименовываются вместе с ней

## Симптом

Генератор формы копирует таблицу-образец и переименовывает её узлы по префиксу имени
(сама таблица, колонки, подсказки, контекстные меню, командная панель). Числовые `id`
уникальны, формы собираются, но имена `…СтрокаПоиска`, `…СостояниеПросмотра`,
`…УправлениеПоиском` повторяются у каждой копии.

## Причина

У таблицы есть три узла-дополнения со своими именами: `searchStringAddition`,
`viewStatusAddition`, `searchControlAddition`. Каждое ещё и указывает на таблицу полем
`source` по имени. Переименование, перечисляющее только «обычные» узлы, их пропускает.

## Как правильно

Переименовывать имена и в узлах дополнений, а `source`, равный прежнему имени таблицы, —
менять на новое. Проверка после генерации — уникальность имён по всем узлам с `name`,
включая дополнения, а не только по `items`.
