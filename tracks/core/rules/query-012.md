# Поле левого соединения - NULL: логическое отрицание над ним падает

## Симптом

На корневых записях (без родителя) падает «Преобразование значения к типу Булево не может быть
выполнено», хотя на остальных записях всё работает.

## Причина

Поле таблицы, присоединённой левым соединением, при отсутствии парной записи приходит `NULL`,
а не `Ложь`. Булево отрицание над `NULL` не вычисляется.

## Правило

Значение сначала вычислять и приводить, `НЕ` применять к вычисленному:

```bsl
// НЕПРАВИЛЬНО
Если НЕ Выборка.РодительПомечен Тогда
// ПРАВИЛЬНО
ПометкаРодителя = (Выборка.РодительПомечен = Истина); // NULL даёт Ложь
Если НЕ ПометкаРодителя Тогда
```

Либо в запросе: `ЕСТЬNULL(Родитель.ПометкаУдаления, ЛОЖЬ) КАК РодительПомечен` (см. bsl-006, query-002 про NULL).

## История

2026-09-17, выгрузка контрагентов из УТ 10: корневые записи иерархии падали, остальные - нет.
