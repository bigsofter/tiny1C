# Ссылочный тип в форме внешней обработки: сборка без базы и с базой

Формат - выгрузка Конфигуратора (`Form.xml`). Сборка: `/LoadExternalDataProcessorOrReportFromFiles`.

## Симптом

Сборка без базы падает «Исключение XDTO произошло при чтении файла ... Form.xml»; `.epf` не
создаётся. В журнале нет имени реквизита, только строка про XDTO.

## Причина

Схема формы при сборке без информационной базы не может разрешить ссылочный тип `cfg:`.
Падает любое имя, включая заведомо несуществующее, - значит, дело не в имени, а в неразрешимости
типа без конфигурации.

## Правило

- Работают без базы: `xs:*`, `v8:ValueTable` со столбцами `xs:*`, пустой `<Type/>` и
  `<v8:TypeSet>cfg:CatalogRef</v8:TypeSet>`.
- Нужны ссылочные типы - собирать с подключённой базой:
  `1cv8 DESIGNER /DisableStartupDialogs /IBConnectionString "File=...;" /LoadExternalDataProcessorOrReportFromFiles <src>/<Имя>.xml <Имя>.epf /Out <лог> -NoTruncate`.
  Тогда реквизит `cfg:CatalogRef.<Имя>` собирается, выгрузка обратно сохраняет тип, а пересборка из
  неё даёт ту же выгрузку.
- Для сборки без базы заменять ссылочные типы строковыми ключами (код, наименование) с поиском по
  базе на сервере.
- Приёмку «сборка не тронула базу» строить не по времени изменения файла базы (сеанс
  Конфигуратора его меняет), а по размеру файла и по журналам Конфигуратора.

## История

2026-09-18: любое `cfg:CatalogRef.<Имя>` ломало сборку, ссылочные типы пришлось заменить
строками. 2026-10-09 (типовая конфигурация УНФ 3.0.14.143, файловая база): с ключом
`/IBConnectionString` тот же реквизит собрался; размер файла базы после сборки не изменился,
время изменения - да.
