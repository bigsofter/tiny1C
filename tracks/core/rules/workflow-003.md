# Форма, открытая без Ключа, выполняется на новом объекте - ветки записанного не проверяются

## Симптом

Смок «открыть все формы» зелёный, а форма падает у пользователя на СУЩЕСТВУЮЩЕМ
объекте.

## Причина

`ПолучитьФорму(Имя)` без параметров выполняет ПриСозданииНаСервере на новом объекте.
Ветки «только для записанного» (проверки по ссылке, чтение движений, вычисления по
заполненным реквизитам) не исполняются.

## Правило

Второй проход прогона: та же форма с `Новый Структура("Ключ", Образец)` по образцу
из базы. Образцы заводит фикстура (в maERP - Обработка.ТестовыеДанные: каждый
документ, каждый справочник, у иерархических - и группа). Ветка «тип значения не
задан» и подобные guard-ветки обязаны существовать: образец приходит с минимально
заполненными данными.

## История

maERP 2026-08-27/31: проход на образцах поднял покрытие с 53 до 106 форм и сразу
поймал две реальных ошибки (query-001, падение формы значений свойств).
