# Корневой модуль расширения требует PropertyState в Configuration.xml

## Симптом

Файл `Ext/ManagedApplicationModule.bsl` загружен, расширение активно, модуль чист,
но `&После("ПриНачалеРаботыСистемы")` не вызывается. Ошибок нет.

## Причина

В `Configuration.xml` расширения (формат выгрузки Конфигуратора) нет записи
о том, что корневой модуль управляемого приложения расширяется. Без неё
файл загружается, а перехватчик не регистрируется.

## Правило

В `Configuration.xml`, в блоке свойств внутреннего описания, должна быть запись:

```xml
<xr:PropertyState>
  <xr:Property>ManagedApplicationModule</xr:Property>
  <xr:State>Extended</xr:State>
</xr:PropertyState>
```

Дефект виден только по молчанию хука: выгрузка расширения обратно содержит этот блок
(платформа дописывает его по наличию файла), поэтому сверка выгрузки с исходниками
ошибку не находит. Исправление - добавить блок в исходники и загрузить заново.

## Как проверить

Сценарий в сеансе: хук должен оставить заметный след (сообщение или файл).

## История

2026-10-13, песочница на копии базы. Хук запуска в активном расширении молчал, пока
блок `PropertyState` не был добавлен в исходный `Configuration.xml`.
