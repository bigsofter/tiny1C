# На круговой диаграмме сектор рисует серия, а не точка

## Симптом

Круговая диаграмма на форме рисуется **одним сплошным кругом** одного цвета, хотя данных несколько
категорий. В легенде — одна строка с именем серии («Заказы», «Остатки», «Выручка»), а не перечень
категорий. Ошибки нет, диаграмма строится, значения в неё попадают.

Если таких диаграмм в конфигурации несколько, все они выглядят одинаково, и это первое, что замечает
владелец: «почему все дашборды на одно лицо».

## Причина

У диаграммы 1С две оси данных: **серии** и **точки**. Для гистограммы и графика категории кладут в
точки (ось X), а серия задаёт один набор значений — и это привычный, многократно написанный код.

У круговой диаграммы роли **обратные**: сектор круга — это серия, а точка задаёт, какой именно круг
рисуется (круговая показывает одну точку). Код, перенесённый с гистограммы «как есть», добавляет одну
серию и N точек — платформа берёт первую точку, видит у неё ровно одну серию и закрашивает ею весь
круг.

## Правило

Заполняя круговую, точку добавляют **один раз до цикла**, а категории — сериями:

Неправильно (схема гистограммы):

```bsl
Диаграмма.ТипДиаграммы = ТипДиаграммы.Круговая;
Серия = Диаграмма.Серии.Добавить("Заказы");
Для Каждого Строка Из Таблица Цикл
	Точка = Диаграмма.Точки.Добавить(Строка(Строка.Статус));
	Диаграмма.УстановитьЗначение(Точка, Серия, Строка.Заказов);
КонецЦикла;
```

Правильно:

```bsl
Диаграмма.ТипДиаграммы = ТипДиаграммы.Круговая;
Точка = Диаграмма.Точки.Добавить("Заказы");
Для Каждого Строка Из Таблица Цикл
	Серия = Диаграмма.Серии.Добавить(Строка(Строка.Статус));
	Диаграмма.УстановитьЗначение(Точка, Серия, Строка.Заказов);
КонецЦикла;
```

Следствие: на круговой **длину легенды определяет число серий**, то есть число категорий. Запрос под
круговую ограничивают (`ВЫБРАТЬ ПЕРВЫЕ 8`) или ставят диаграмме `МаксимумСерий = МаксимумСерий.Ограничено`
с `МаксимумСерийКоличество`. Без этого круговая по сотрудникам или контрагентам на живой базе
превращается в легенду во весь виджет.

## Как проверить

Глазами на данных, где категорий три и больше: сплошной одноцветный круг — это она. На пустой или
одноэлементной выборке ошибка неотличима от нормы, поэтому демо-данные должны давать несколько
категорий.

Ни статический анализ, ни проверка конфигурации, ни смок «открыть все формы» этого не видят: код
корректен, форма открывается, исключения нет.

## История

maERP, 2026-09-23. Три круговые диаграммы — «Остатки по товарным группам», «Выручка по сотрудникам»,
«Активные заказы по статусам» — были написаны по образцу соседних гистограмм и полгода рисовали
сплошной синий круг. Заметили не по коду, а по скриншотам: владелец сказал, что все три дашборда
выглядят одинаково.

Подтверждение нашлось в УНФ 3.0.14 (`Обработка.ПульсБизнеса`): в ветке круговой она ставит
`УстановитьТочку(ПредставленияСерий[0])` один раз, а в цикле меняет `УстановитьСерию(...)`; и для
круговой ограничивает именно `МаксимумСерий`. Ограничение числа серий имеет смысл только тогда, когда
сектор — это серия.
