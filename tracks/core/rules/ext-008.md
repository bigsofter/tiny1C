# Форма расширения из файлов: три файла и проверка открытием

Формат - выгрузка Конфигуратора (`Form.xml`), не EDT (`Form.form`).

## Симптом

Нужна новая управляемая форма собственного объекта расширения, и неясно, соберётся ли она
из файлов: ранняя заметка (2026-09-17) утверждала, что новые формы так не собираются.

## Причина

Ранняя заметка не подтвердилась: 2026-10-13 форма собралась. Почему ранний прогон дал другой
результат, не установлено.

## Правило

`LoadConfigFromFiles -Extension` создал и обновил управляемую форму собственного
объекта расширения по трём файлам:

```
<Объект>/Forms/<Форма>.xml                  стаб описания формы
<Объект>/Forms/<Форма>/Ext/Form.xml         описание элементов, команд, реквизитов
<Объект>/Forms/<Форма>/Ext/Form/Module.bsl  модуль формы
```

Нужна ли строка формы в перечислении `ChildObjects` XML объекта-владельца, в наблюдении не
рассматривалось.

Проверять, что форма собралась, надо открытием, а не выгрузкой. Выгрузка обратно
должна совпасть с исходниками, а в сеансе форму открывает клиентский код
(в клиентском, не в серверном модуле):

```bsl
Форма = ПолучитьФорму("Обработка.Пример.Форма.Основная");
Форма.Открыть();
// затем чтение Форма.Элементы, Форма.Команды, реквизитов формы; Форма.Закрыть()
```

Нюанс проверки: `ПолучитьФорму()` - клиентский метод (в серверном общем модуле даёт
«Процедура или функция с указанным именем не определена»), а `ПолучитьДействие()` -
серверный (на клиенте «Метод недоступен на клиенте»).

## Как проверить

Выгрузка расширения обратно без расхождений, затем открытие формы клиентским кодом, как выше.

## История

2026-10-13, песочница и рабочая база. Новая обработка расширения была собрана из
файлов, выгрузка обратно вернула форму без расхождений, сеанс тонкого клиента открыл
её: элемент таблицы и три команды были на месте. Это не подтверждает ранний вывод
2026-09-17, что формы так не собираются (см. ext-002).
