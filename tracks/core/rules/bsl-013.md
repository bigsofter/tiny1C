# У коллекции элементов отбора компоновки нет метода «Найти»

## Симптом

Форма списка не открывается, при создании формы на сервере:

```
{Документ.КоммерческоеПредложение.Форма.ФормаСписка.Форма(127)}: Метод объекта не обнаружен (Найти)
    ЭлементОтбора = Список.КомпоновщикНастроек.Настройки.Отбор.Элементы.Найти(ИмяПоля);
[ОшибкаВоВремяВыполненияВстроенногоЯзыка, ОшибкаИспользованияВстроенногоЯзыка]
```

На испанском интерфейсе — `El método del objeto no encontrado (Найти)`. Ни BSL LS, ни CheckConfig строку не отмечают:
тип коллекции известен только при выполнении.

## Причина

`Отбор.Элементы` — `КоллекцияЭлементовОтбораКомпоновкиДанных`. У неё есть `Добавить`, `Вставить`, `Удалить`, `Индекс`,
`Количество`, `Получить`, `Очистить`, но нет поиска: элементы бывают группами (`ГруппаЭлементовОтбораКомпоновкиДанных`),
у них нет имени, а левое значение — `ПолеКомпоновкиДанных`, а не строка. Метод `Найти(ИмяПоля)` есть у других коллекций
компоновки (например, доступных полей), отсюда ложная аналогия.

## Правило

Элемент отбора ищется перебором: только элементы типа `ЭлементОтбораКомпоновкиДанных` с равным `ПолеКомпоновкиДанных`.

```bsl
// НЕПРАВИЛЬНО
ЭлементОтбора = Список.Отбор.Элементы.Найти(ИмяПоля);

// ПРАВИЛЬНО
ПолеКомпоновки = Новый ПолеКомпоновкиДанных(ИмяПоля);
ЭлементОтбора = Неопределено;
Для Каждого Элемент Из Список.Отбор.Элементы Цикл
	Если ТипЗнч(Элемент) = Тип("ЭлементОтбораКомпоновкиДанных") И Элемент.ЛевоеЗначение = ПолеКомпоновки Тогда
		ЭлементОтбора = Элемент;
		Прервать;
	КонецЕсли;
КонецЦикла;
```

## Как проверить

- До передачи на базу — поиск `Отбор\.Элементы\.Найти\(` по изменённым модулям.
- Смок «открыть все формы» падает на форме с этим кодом в `ПриСозданииНаСервере`.

## История

maERP 2026-09-14: форма списка коммерческих предложений с 2.0.15.8 строила отборы панели через `Отбор.Элементы.Найти`.
Ошибку долго не видели: модуль формы не доезжал до тестовой базы при неполных обновлениях, а соседние списки уже
искали элемент перебором. Поймал смок на полностью обновлённой базе 2.0.15.26.
