# У ДанныеФормыСтруктура нет метода Метаданные()

## Симптом

`El método del objeto no encontrado (Метаданные)` в общем коде, который зовут и по
ссылке/объекту, и с формы.

## Причина

С формы приходит `ДанныеФормыСтруктура` - у неё нет `Метаданные()`. Зато
`Данные.Ссылка.Метаданные()` работает для всех трёх случаев: ссылки, объекта и
данных формы.

```bsl
// ПРАВИЛЬНО - универсально
Если Док.Ссылка.Метаданные().Реквизиты.Найти("X") <> Неопределено Тогда
```

## Правило: Объект в модуле управляемой формы

В модуле управляемой формы `Объект` - это данные формы, а не объект метаданных, поэтому и
`Объект.Метаданные()` падает: «Метод объекта не обнаружен (Метаданные)». Кроме
`Данные.Ссылка.Метаданные()` есть ещё два способа получить метаданные:

- глобальный объект `Метаданные`: `Метаданные.Документы.<Имя>.ТабличныеЧасти.Найти("Запасы")` -
  он отражает фактическую конфигурацию вместе с расширениями;
- `РеквизитФормыВЗначение("Объект").Метаданные()` (дорого: копирует данные формы в объект).

```bsl
// НЕПРАВИЛЬНО
ТаблицаЗапасов = Объект.Метаданные().ТабличныеЧасти.Найти("Запасы");
// ПРАВИЛЬНО
ТаблицаЗапасов = Метаданные.Документы.ЗаказКлиента.ТабличныеЧасти.Найти("Запасы");
```

Остальное у `Объекта` формы работает как у объекта: реквизиты (`Объект.Организация`), строки
табличных частей, запись в них, `Объект.Ссылка`; реквизиты справочников от полей строки формы
читаются напрямую (`СтрокаТаблицы.Номенклатура.ТипНоменклатуры`).

## История

maERP 2026-08-26: ПолучитьСпособОплаты падал при открытии форм налоговых накладных.

2026-10-05, проект на 1С:УНФ, платформа 8.5.1.1529: форма документа заказа покупателя
получала состав табличной части через `Объект.Метаданные()` и падала при открытии; замена на
глобальный `Метаданные.Документы...` исправила (имена объектов в примере вымышленные).
