# Имя предопределённых данных и наименование - разные поля

## Симптом

`Справочники.ВидыЦен.НайтиПоНаименованию("Оптовая", Истина)` возвращает пустую ссылку, хотя вид цены
«Оптовая» в справочнике есть.

## Причина

У предопределённого элемента два независимых поля: имя предопределённых данных (`Name` в
`Ext/Predefined.xml`, выгрузка Конфигуратора) и наименование (`Description`, то, что видит
пользователь). У вида цены имя `Оптовая`, а наименование `Оптовая цена`; поиск по наименованию
ищет по второму.

## Правило

- Надёжный ключ - статическое обращение: `Справочники.ВидыЦен.Оптовая`.
- При сопоставлении типовых предопределённых элементов по «наименованию» (виды цен,
  состояния, единицы, склады) проверять пару `Name`/`Description` в `Predefined.xml`, а не
  представление в интерфейсе.

```bsl
// НЕПРАВИЛЬНО
Вид = Справочники.ВидыЦен.НайтиПоНаименованию("Оптовая", Истина);
// ПРАВИЛЬНО
Вид = Справочники.ВидыЦен.Оптовая;
```

## История

2026-09-18, загрузка видов цен в базу на 1С:УНФ 3.0.14.143: поиск по «Оптовая» не находил
вид цены с наименованием «Оптовая цена». Рабочее решение - поиск по наименованию, затем
сопоставление по имени предопределённых данных.
