# Режим совместимости расширения не выше режима основной конфигурации

## Симптом

`UpdateDBCfg -Extension "<Имя>"` завершается кодом 101 и сообщением «Режим совместимости
расширения конфигурации больше режима совместимости основной конфигурации».

## Причина

В `Configuration.xml` расширения (выгрузка Конфигуратора) задан
`ConfigurationExtensionCompatibilityMode` выше, чем `CompatibilityMode` основной
конфигурации.

## Правило

Брать в расширении то же значение, что стоит у основной конфигурации
(например `Version8_3_27`), либо ниже. Перед загрузкой сверять значение в
`Configuration.xml` расширения с основной конфигурацией.

```xml
<!-- НЕПРАВИЛЬНО при основной конфигурации Version8_3_27 -->
<ConfigurationExtensionCompatibilityMode>Version8_5_1</ConfigurationExtensionCompatibilityMode>
<!-- ПРАВИЛЬНО -->
<ConfigurationExtensionCompatibilityMode>Version8_3_27</ConfigurationExtensionCompatibilityMode>
```

## Как проверить

`UpdateDBCfg -Extension` после загрузки; код 0 и отсутствие сообщения.

## История

2026-10-12, песочница на копии базы типовой конфигурации с режимом совместимости
Version8_3_27: расширение с Version8_5_1 загрузилось, а применение к базе упало
с кодом 101.
