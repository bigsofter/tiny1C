# ПланыСчетов.НайтиПоКоду: второй параметр - родитель

## Симптом

`ПланыСчетов.Хозрасчетный.НайтиПоКоду(Код, Ложь)` падает: «Несоответствие типов (параметр
номер '2')».

## Причина

У менеджера плана счетов второй параметр метода - родитель (ссылка на счёт или
`Неопределено`), а не булев признак. У справочников (`Справочники.<Имя>.НайтиПоКоду(Код, Ложь)`)
второй параметр другой, и тот же вызов безопасен: не переписывать его без повода.

## Правило

Для плана счетов искать счёт запросом (по справочнику-аналогу не угадывать сигнатуру):

```bsl
// НЕПРАВИЛЬНО
Счет = ПланыСчетов.Хозрасчетный.НайтиПоКоду(Код, Ложь);
// ПРАВИЛЬНО
Запрос.Текст = "ВЫБРАТЬ ПЕРВЫЕ 2 Счета.Ссылка ИЗ ПланСчетов.Хозрасчетный КАК Счета ГДЕ Счета.Код = &Код";
```

Если в запросе нашлись два счёта, код неоднозначен, это отдельный случай.

## История

2026-09-24, перенос данных в БП обработкой: вызов с булевым вторым параметром упал в первом
боевом прогоне; в индексе API платформы метод не нашёлся, поэтому сверка «по справке» не помогла.
Справочники тем же вызовом искались без ошибок (валюта находилась по коду).
