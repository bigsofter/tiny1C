# При загрузке данных проведение запрещено

## Симптом

`Объект.Записать(РежимЗаписиДокумента.Проведение)` при включённом `ОбменДанными.Загрузка`
падает: «Действие не может выполняться в режиме загрузки данных».

## Причина

Флаг загрузки включает режим, в котором проведение запрещено. Измерение: 6522 документа с
признаком «проведён» дали эту ошибку, а 521 непроведённый документ, записанный тем же кодом
режимом `Запись`, записался без ошибок; разница только в режиме записи.

## Правило

Проведение - вторым проходом: сначала запись с `ОбменДанными.Загрузка = Истина`
режимом `Запись`, затем отдельно `Загрузка = Ложь` и `Записать(РежимЗаписиДокумента.Проведение)`.

```bsl
// НЕПРАВИЛЬНО
Объект.ОбменДанными.Загрузка = Истина;
Объект.Записать(РежимЗаписиДокумента.Проведение);
// ПРАВИЛЬНО: проход 1
Объект.ОбменДанными.Загрузка = Истина;
Объект.Записать(РежимЗаписиДокумента.Запись);
// проход 2, отдельный вызов
Объект.ОбменДанными.Загрузка = Ложь;
Объект.Записать(РежимЗаписиДокумента.Проведение);
```

## Как проверить

Загрузка на копии базы: сравнить число документов, записанных и проведённых после обоих проходов.

## История

2026-09-24, перенос документов УТ 10 в БП. 6522 документа с признаком «проведён» дали
именно эту ошибку, 521 непроведённый документ, записанный тем же кодом режимом
`Запись`, записался без ошибок: разница только в режиме записи.
