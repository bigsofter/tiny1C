# Ключи с точкой - в Соответствие; у Соответствия нет метода Свойство

## Симптом

1. `Структура.Вставить("Counterparties.xml", ...)` падает во время выполнения:
   «Задано неправильное имя атрибута структуры».
2. `Кэш.Свойство(Ключ)`, где `Кэш` - `Соответствие`, падает: «Метод объекта не обнаружен
   (Свойство)».

## Причина

Ключ `Структуры` обязан быть допустимым идентификатором: без точки, пробела и подобных
знаков. Метод `Свойство` есть только у `Структуры`; `Соответствие` ключи не ограничивает,
но и этого метода не имеет.

## Правило

- Ключи вида имени файла, «ИмяТипа|uuid», наименований с пробелами - только `Соответствие`.
- Наличие ключа в `Соответствии`: `Кэш.Получить(Ключ) <> Неопределено`. Чтобы отличать «ключа
  нет» от сохранённого отрицательного результата, класть отрицательный результат маркером,
  например `Новый Структура("НетЗначения", Истина)`.

```bsl
// НЕПРАВИЛЬНО
Кэш = Новый Соответствие;
Если Кэш.Свойство(Ключ) Тогда
Файлы.Вставить("Контрагенты.xml", Данные);   // Файлы - Структура
// ПРАВИЛЬНО
Значение = Кэш.Получить(Ключ);
Если Значение <> Неопределено Тогда
Файлы = Новый Соответствие; Файлы.Вставить("Контрагенты.xml", Данные);
```

## Как проверить

Выполнение ветки: компилятор обе строки пропускает.

## История

2026-09-24, перенос документов УТ 10 в БП обработкой, прогон на базе: оба падения
встретились в первом же прогоне.
