# Метаданные сверять с базой, а не с лежащей рядом выгрузкой

## Симптом

Запрос падает «Поле не найдено "Единицы.ЭтоГруппа"», хотя в выгрузке справочник иерархический и
поле `ЭтоГруппа` есть.

## Причина

Выгрузка конфигурации в каталоге проекта бывает снята с другой версии, чем база, для которой
пишется код. В выгрузке справочник иерархический, а в рабочей базе - нет.

## Правило

- Неочевидные поля и признаки (иерархичность, реквизиты, измерения) перед использованием
  проверять по рабочей базе: выгрузкой нужного объекта или тестовым запросом.
- Значения по умолчанию брать из данных, уже лежащих в базе (склад и организация из последнего
  документа), а не угадывать по структуре справочников.

## Как проверить

Тестовый запрос к рабочей базе по нужным полям до сборки кода. См. mdo-008 про `hierarchical`.

## История

2026-09-17, расширение к 1С:УНФ: документы не создавались из-за поля, которого в рабочей базе
не было, при том что выгрузка в проекте его показывала.
