# Шпаргалки платформы

Короткие справки по языку запросов и виртуальным таблицам регистров — для
помощника, который работает в базе 1С и пишет запросы сам. Инструмент
`get_cheats` отдаёт их целиком, в промпт они кладутся как есть.

Происхождение: тексты перенесены 1:1 из системных промптов ИИ-помощника 1С
портала TinyCIO (образец: `cheat-queries`, `cheat-accumulation`,
`cheat-accounting`, `cheat-calculation`, состояние на 2026-10-27); источник
самих текстов — документация платформы, пересказанная своими словами, и
практика ответов помощника. Подстановки `%ПланСчетов%` и `%ВидыСубконто%` в
`accounting.md` заполняет сервер из `profile.json` направления
(`план_счетов`, `виды_субконто`).

Файл — одна тема, первая строка `# Заголовок`; потолок всех шпаргалок — 24 КБ
(`scripts/manifest.py`). README в набор не входит.
