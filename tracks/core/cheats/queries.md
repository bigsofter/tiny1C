# Язык запросов 1С

Синтаксис: ВЫБРАТЬ [РАЗЛИЧНЫЕ] [ПЕРВЫЕ N] Поля [ПОМЕСТИТЬ ВТ] ИЗ Таблица КАК Псевдоним [ЛЕВОЕ|ВНУТРЕННЕЕ|ПОЛНОЕ СОЕДИНЕНИЕ … ПО …] [ГДЕ …] [СГРУППИРОВАТЬ ПО …] [ИМЕЮЩИЕ …] [ОБЪЕДИНИТЬ ВСЕ …] [УПОРЯДОЧИТЬ ПО … [УБЫВ]] [ИТОГИ … ПО …]. РАЗРЕШЕННЫЕ добавляется автоматически. Пакет запросов разделяется ";" (результат — последний запрос пакета). Параметры — &Имя (значения передаются в parameters). Ключевые слова — по-русски (не SELECT/LIMIT/TOP). Псевдонимы — КАК. Условия: =, <>, >, <, И, ИЛИ, НЕ, В (&Список), В ИЕРАРХИИ(&Группа), МЕЖДУ &Н И &К, ПОДОБНО "%текст%" (регистр: в файловой базе и MS SQL не важен, в PostgreSQL важен — используй ВРЕГ()), ЕСТЬ NULL, ССЫЛКА Справочник.X.
Имена таблиц: Справочник.X, Документ.X, Документ.X.ТабличнаяЧасть (поля Ссылка, НомерСтроки + реквизиты ТЧ), РегистрСведений.X, РегистрНакопления.X, РегистрБухгалтерии.X, РегистрРасчета.X, ПланСчетов.X, ПланВидовХарактеристик.X, Перечисление.X (поля Ссылка, Порядок), ЖурналДокументов.X, Константа.X (поле Значение). Точные имена — через search_metadata/describe_metadata.
Стандартные поля: Справочник — Ссылка, Код, Наименование, ПометкаУдаления, Предопределенный, ИмяПредопределенныхДанных, Родитель, ЭтоГруппа (только у иерархических справочников), Владелец (только у подчинённых); Документ — Ссылка, Номер, Дата, Проведен, ПометкаУдаления; регистр — Период, Регистратор, НомерСтроки, Активность (+ измерения, ресурсы, реквизиты). Представление: ПРЕДСТАВЛЕНИЕ(Поле) даёт строку; для ссылочных полей запрос возвращает ссылку (в результате — представление и [R-идентификатор]).
Разыменование: К.Контрагент.ИНН (неявное соединение). Приведение типа: ВЫРАЗИТЬ(Поле КАК Справочник.Контрагенты).Наименование, ВЫРАЗИТЬ(Поле КАК Число(15,2)), ВЫРАЗИТЬ(Строка КАК Строка(100)). Тип: ТИПЗНАЧЕНИЯ(Поле) = ТИП(Справочник.Контрагенты). NULL: ЕСТЬNULL(Поле, 0). Условие: ВЫБОР КОГДА … ТОГДА … ИНАЧЕ … КОНЕЦ. Значения перечислений и предопределённые элементы прямо в тексте: ЗНАЧЕНИЕ(Перечисление.X.Y), ЗНАЧЕНИЕ(Справочник.X.ПустаяСсылка).
Даты: ДАТАВРЕМЯ(2026, 9, 30, 23, 59, 59); НАЧАЛОПЕРИОДА(&Дата, МЕСЯЦ), КОНЕЦПЕРИОДА(&Дата, КВАРТАЛ) — ГОД, КВАРТАЛ, МЕСЯЦ, ДЕКАДА, НЕДЕЛЯ, ДЕНЬ, ЧАС, МИНУТА; ДОБАВИТЬКДАТЕ(&Дата, ДЕНЬ, -1); РАЗНОСТЬДАТ(Д1, Д2, ДЕНЬ); ГОД(Д), МЕСЯЦ(Д), ДЕНЬ(Д), ДЕНЬНЕДЕЛИ(Д). Период документов: Дата МЕЖДУ &Начало И &Конец, где &Конец = конец дня (23:59:59). Пустая дата — ДАТАВРЕМЯ(1, 1, 1).
Агрегаты: СУММА, КОЛИЧЕСТВО(*), КОЛИЧЕСТВО(РАЗЛИЧНЫЕ Поле), МИНИМУМ, МАКСИМУМ, СРЕДНЕЕ. Все неагрегированные поля — в СГРУППИРОВАТЬ ПО. Строковые: ПОДСТРОКА(С, 1, 10), ВРЕГ, НРЕГ, СОКРЛП, ДЛИНАСТРОКИ, СТРНАЙТИ(С, "x"), СТРЗАМЕНИТЬ(С, "a", "b").
Виртуальные таблицы регистров (параметры — в скобках, Условие — выражение по измерениям, &Период — дата или Граница): РегистрСведений.X.СрезПоследних(&Период, Условие) / СрезПервых — для периодических регистров (актуальные значения на дату). Периодичность: Период, Запись, Регистратор, Секунда, Минута, Час, День, Неделя, Декада, Месяц, Квартал, Полугодие, Год, Авто. Пропущенный параметр оставляй пустым: Остатки(, Организация = &Организация).
Типичные ошибки: 1) неверное имя таблицы/реквизита — проверь describe_metadata; 2) поле не в СГРУППИРОВАТЬ ПО; 3) виртуальная таблица оборотов без параметров периода отклоняется — всегда задавай &Начало/&Конец и условие по организации; 4) сравнение даты документа с датой без времени (теряется последний день); 5) непроведённые документы — добавляй ГДЕ Проведен; помеченные на удаление — ГДЕ НЕ ПометкаУдаления; 6) ПОДОБНО без % ищет точное совпадение; спецсимволы % _ [ экранируются через СПЕЦСИМВОЛ; 7) разыменование через поля составного типа — сначала ВЫРАЗИТЬ; 8) ИТОГИ усложняют результат — для простых сводок используй СГРУППИРОВАТЬ ПО; 9) УПОРЯДОЧИТЬ ПО полю, которого нет в выборке при РАЗЛИЧНЫЕ/СГРУППИРОВАТЬ — ошибка; 10) ПЕРВЫЕ N без УПОРЯДОЧИТЬ даёт произвольные строки; 11) ссылочные параметры передавай как {"ref":"R12"}, даты как {"date":"…"}, значения перечислений — ЗНАЧЕНИЕ(Перечисление.X.Y) прямо в тексте запроса; 12) псевдоним не может быть ключевым словом (КАК В, КАК ИЗ, КАК Выбор — синтаксическая ошибка) — давай осмысленные псевдонимы.
