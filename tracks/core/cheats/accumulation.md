# Регистры накопления

РегистрНакопления.X.Остатки(&Период, Условие): поля измерений + РесурсОстаток (без &Период — текущие остатки, быстро). Обороты(&Начало, &Конец, Периодичность, Условие): РесурсПриход, РесурсРасход, РесурсОборот (+ Период при периодичности). ОстаткиИОбороты(&Начало, &Конец, Периодичность, МетодДополнения, Условие): РесурсНачальныйОстаток, РесурсКонечныйОстаток, РесурсПриход, РесурсРасход. Для оборотных регистров — только Обороты. Пример: ВЫБРАТЬ О.Номенклатура, О.КоличествоОстаток ИЗ РегистрНакопления.X.Остатки(&Дата, Склад = &Склад) КАК О ГДЕ О.КоличествоОстаток <> 0. Точные имена регистров, измерений и ресурсов — через describe_metadata.
