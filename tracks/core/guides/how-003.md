# Выбор из списка в колонке таблицы формы: кнопка выбора, НачалоВыбора и ПоказатьВыборИзСписка

Путь добыт после неудачной попытки задать список через свойство `СписокВыбора` колонки
из кода (см. «Где ломается»). Рабочий порядок - штатная кнопка выбора у колонки,
обработчик начала выбора и показ списка с оповещением. Имена в примерах вымышленные.

## Шаги

1. У колонки таблицы включить кнопку выбора и повесить обработчик начала выбора. В
   Конфигураторе это свойство «Кнопка выбора» и событие «НачалоВыбора» колонки; в выгрузке
   формы (формат Конфигуратора) у элемента колонки внутри `<Table>` появляются
   `<ChoiceButton>true</ChoiceButton>` и событие `StartChoice` с именем процедуры. Если
   правите XML руками - взять форму из выгрузки этой базы и сверить написание с соседними
   элементами, у которых кнопка выбора уже есть.
2. В модуле формы - клиентский обработчик начала выбора. Он отключает стандартную
   обработку, собирает список и показывает его с оповещением о выборе:

   ```bsl
   &НаКлиенте
   Процедура СтрокиСтатусНачалоВыбора(Элемент, ДанныеВыбора, СтандартнаяОбработка)
       СтандартнаяОбработка = Ложь;
       Список = Новый СписокЗначений;
       Список.Добавить("Новый", НСтр("ru = 'Новый'"));
       Список.Добавить("ВРаботе", НСтр("ru = 'В работе'"));
       Оповещение = Новый ОписаниеОповещения("СтрокиСтатусВыборЗавершение", ЭтотОбъект);
       ПоказатьВыборИзСписка(Оповещение, Список, Элемент);
   КонецПроцедуры
   ```

   Представления списка - на всех языках конфигурации (forms-010).
3. Процедура завершения - экспортная, принимает выбранный элемент списка (или
   `Неопределено`, если список закрыли) и пишет значение в текущую строку таблицы:

   ```bsl
   &НаКлиенте
   Процедура СтрокиСтатусВыборЗавершение(ВыбранныйЭлемент, ДополнительныеПараметры) Экспорт
       Если ВыбранныйЭлемент = Неопределено Тогда
           Возврат;
       КонецЕсли;
       ТекущиеДанные = Элементы.Строки.ТекущиеДанные;
       Если ТекущиеДанные <> Неопределено Тогда
           ТекущиеДанные.Статус = ВыбранныйЭлемент.Значение;
       КонецЕсли;
   КонецПроцедуры
   ```

4. Если тот же список нужен из нескольких форм и показ выносится в общий клиентский
   модуль - форму передавать параметром и вызывать `Форма.ПоказатьВыборИзСписка(...)`;
   цель оповещения тогда - сам общий модуль (bsl-020).
5. Если элемент таблицы потом пересоздавали в Конструкторе - вернуть кнопку выбора и
   обработчик у колонки: они сбрасываются (forms-026).

## Проверка результата

Смоук формы: открыть, добавить строку (штатной командой таблицы - forms-026), нажать
кнопку выбора в колонке - открылся список, после выбора значение читается из строки
(`Элементы.<Таблица>.ТекущиеДанные.<Колонка>`). Без смоука - глазами в сеансе те же три
признака.

## Где ломается

- Присвоение свойству `СписокВыбора` колонки нового списка из кода
  (`Элементы.<Таблица><Колонка>.СписокВыбора = ...`) в наблюдении падало «Поле объекта
  недоступно для записи», чтение свойства работало. Проверено на колонке таблицы,
  привязанной к реквизиту формы типа ТаблицаЗначений, платформа 8.5.1.1529, одна форма;
  заполнение того же списка на месте (`СписокВыбора.Добавить(...)`) в наблюдении не
  проверялось. Отсюда рецепт: список собирать в момент выбора.
- `ПоказатьВыборИзСписка` вызван в общем модуле без формы - ошибка компиляции «Процедура
  или функция с указанным именем не определена» (bsl-020).
- Список показывает значения вместо подписей на другом языке - представления заданы для
  одного языка (forms-010).
- Строка для выбора не добавляется, хотя `ДобавитьСтроку()` без ошибки, - в панели таблицы
  нет штатной команды «Добавить» (forms-026).
- После пересоздания таблицы в Конструкторе кнопка выбора и обработчик у колонки пропали
  (forms-026).
